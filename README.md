# SIDEY

SIDEY의 공식 공개 배포·지원 저장소예요.

- [공식 웹사이트](https://sidey-app.github.io/SIDEY/)
- [Mac App Store](https://apps.apple.com/kr/app/sidey/id6808528060?mt=12)
- [Windows 다운로드 및 릴리스 노트](https://github.com/sidey-app/SIDEY/releases)
- [버그 신고](https://github.com/sidey-app/SIDEY/issues/new/choose)

현재 애플리케이션과 웹사이트의 원본 소스코드는 비공개로 관리합니다. 이 저장소는
공식 웹사이트, 공개 정책, 릴리스 메타데이터와 설치 파일을 제공하며 현재 제품의
소스 저장소가 아닙니다.

라이선스 전환 전에 공개된 revision의 기존 오픈소스 권리는 철회되지 않아요. 계속
배포하는 AGPL 적용 릴리스의 정확한 Corresponding Source는 해당 GitHub Release에
함께 보존합니다. 자세한 내용은 [라이선스 안내](LICENSING.md)를 확인해 주세요.

공개 Issues에서는 재현 가능한 제품 버그만 접수합니다. 기능 제안과 외부 Pull Request,
코드·문서·번역·에셋 제출은 받지 않습니다. 신고 범위와 개인정보 주의사항은
[버그 신고 안내](CONTRIBUTING.md)를 따라 주세요.
