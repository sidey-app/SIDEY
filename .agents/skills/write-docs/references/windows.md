# Windows Developer Documentation Reference

Read this reference only for Windows-owned developer documentation. Apply `windows/AGENTS.md` and, for `windows/docs/**`, `windows/docs/AGENTS.md` first.

Windows contributor guides live under `windows/docs/**`. The Korean edition is `windows/docs/{topic}.md` and its English edition is `windows/docs/en/{topic}-en.md`; keep their technical claims, commands, headings and language-appropriate links aligned when either changes.

Trace claims to current C# or XAML, tests, project metadata, scripts, packaging inputs and CI. Follow the non-installing validation route in `windows/AGENTS.md` when application evidence is required. Installation, prerequisite provisioning, elevation, GUI launch, release access, network download and other machine-state changes remain separately authorized operations.
