# 직배포판 캐릭터 피드백 작업 기록

확정일: 2026-09-09. 대상: macOS 직배포판 / Sidey-dev. App Store·Windows·웹 제외.

## 승인 계약

사용자가 효과음과 기절 PNG·애니메이션을 적용 전에 함께 검토하도록 요청했다. 구현 지시는 개별 에셋 승인을 대체하지 않는다. 음원·시각의 승인은 별도로 기록하고 승인된 파일 SHA-256과 연출 수치를 고정한다. 변경된 음량·음색·이미지·회전 수치는 재승인한다.

1. 1차: 말랑공·확대음 각 3개, 햄스터 기절 PNG·별 PNG·GIF를 함께 제출한다.
2. 기준 톤·시각 피드백 뒤: 나머지 투척물 7종 각 3개, 전체 9종 캐릭터 합성 PNG를 제출한다.
3. 최종: 음원 9개, 별 PNG, 전체 캐릭터 PNG, 반복·혼합 청취 및 소리 포함 기절 영상에 대한 승인을 받는다.
4. 승인 원본·manifest를 shared 변경으로 반영한 뒤 별도 macos 브랜치에 가져와 구현한다.

## 현재 상태

- 제품 동작 확정: 10초 내 10회, 6초 기절, 보호 시간 없음, 기절 중 누적 없음, 채팅 유지·확대/던지기 잠금.
- 최신 검토 자료: `round-4/index.html`. 피격음 8종 × 3개를 모두 재제작하고 확대 C 기반 3개를 그대로 포함해 총 27개를 제공한다. 이전 후보와 기절 V2는 보존한다.
- 음원 승인: **새 피격음 24개 모두 대기**. 과거 말랑공 C 선택은 새 버전에 승계하지 않는다. 확대는 C 방향을 기준으로 길이 후보 선택 대기. 시각 승인: **2026-09-10 기절 선행 구현 지시로 별·링 V2 적용 승인**.
- 기절은 `macos/character-stun`에서 구현·검증 완료. 효과음 연결·소리 설정·schema 변경은 보류.
- 검토 디렉터리는 `assets/v1` 승인 원본·앱 번들에 포함하지 않는다. 선택된 말랑공도 전체 에셋 승인 작업과 분리해 임의로 앱에 연결하지 않는다.

## 피드백 기록

2026-09-09 사용자 피드백:

- 기절 PNG: “별돌아가는거 지금 좋은데 링? 같은게 추가로 있었으면 좋겠음.” 기존 별 모양·좌표·1.2초 회전은 유지하고 1px 링을 추가하는 방향으로 반영했다. 별 회전에 대한 긍정 피드백이며 새 링이 포함된 최종 시각 에셋 승인은 대기다.
- 말랑공 소리: “뒤로갈수록 음이 낮아지는 느낌… 힘빠짐… 좀더 발랄 귀엽… 말랑공답게.” 내려가는 저음 꼬리를 없애고 짧은 상승·두 번의 탄성·부드러운 상승 세 후보를 새로 제작했다.
- 확대음: “완전 다른 분위기의 3개의시안… 맘에드는걸 고르고 다듬는식… 지금 다 너무 비슷.” 풍선 장난감·마법 종소리·8비트 레벨업의 독립적 방향을 제안한다. 후보 선택과 최종 승인 모두 아직 대기다.

2026-09-09 추가 피드백:

- “둘다 C가 좋고”로 말랑공 `hit-c-v2`와 확대의 C 방향을 선택했다. 말랑공은 동일 파일 사용으로 선택을 확정한다.
- “커지는건 너무 음들이 짧다고해야하나? C기준 세가지 안”에 따라 기존 네 음·8비트 음색을 유지하고 길이·지속감을 늘린 C-1/C-2/C-3을 제작한다. 이전 음색 방향 탐색은 종료하고 이 세 후보의 선택을 받는다.
- “나머지 투척물들 효과음들도 다”에 따라 나머지 7종 각 3개 후보를 함께 제출한다. 기절 V2 링의 최종 승인은 아직 받지 않았다.

2026-09-10 추가 피드백:

- “맞는 상황의 음임. 던지는 음은 없음 … 다시 다해봐”에 따라 피격음 8종 전체를 재작업했다. 시작부터 짧은 타격이 들리게 하고 상승·발사 인상의 멜로디를 제거한다.
- “오리답게 꽥꽥 … 대포답게 펑”에 따라 오리 울음과 충돌 폭발의 CC0 샘플을 편집한다. 원본·출처·라이선스는 `round-4/sources/manifest.json`에 기록한다.
- 확대는 별도 피격음이 아니므로 3차 C 기반 세 WAV를 동일 바이트로 유지했다. 링 V2도 보존한다. 4차 후보는 아직 앱에 적용하지 않는다.

## 기절 선행 구현 승인 · 2026-09-10

사용자가 효과음 작업을 다음 날로 미루고 기절만 먼저 구현하도록 지시했다. 현재 별·링 V2와 기존 수면 모션 적용 승인으로 기록한다. 기절을 별도 macOS 직배포 브랜치에서 구현·검증한다. 음원 승인 및 소리 설정/schema 작업은 보류하며 기절 구현의 선행 조건에서 분리한다.

## 기절 구현 검증 · 2026-09-10

- `macos/character-stun`에 실제 충돌 시점의 판정, 수면 2프레임·별 3개·링, 입력 차단과 상태 정리를 구현했다. 승인 별·링 PNG는 검토 파일과 번들에서 SHA-256이 동일하다.
- 직배포 `SIDEY` 빌드와 전체 XCTest: 267건 중 266건 통과, 명시적인 staging을 요구하는 기존 백엔드 통합 1건 제외, 실패 0건. 신규 기절 테스트는 8건이다.
- 10초 경계·6초 회복·중복 투척·기절 중 피격·입력 차단 전 cooldown 보존·채팅 초안 보존·외형 변경·방 전환·대상 제거·재연결을 검증했다. 9종 × 4개 가장자리 × 5개 Presence 조합에서 수면·표시색·타이핑을 확인했다. 모션 감소 시 별 좌표 고정과 네이티브 SpriteKit 합성 PNG를 확인했다.
- App Store는 빌드하지 않고 컴파일 조건과 해당 타깃 PNG 제외 목록을 정적으로 확인했다. Windows·오디오·설정 schema는 이번 구현 커밋에 없다.
- 실제 두 클라이언트 세션과 30분 부하·배포 검증은 아직 수행하지 않았다. 음원 검토는 4차 자료에서 다음 작업으로 이어간다.
