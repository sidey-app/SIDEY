# 피격음 4차 검토

2026-09-10 · macOS 직배포판용 후보. 앱 적용 전 사용자 승인 대기.

[검토 페이지](index.html)에서 피격 8종 × A/B/C와 확대 C-1/C-2/C-3을 듣는다. 오리·대포를 먼저 배치했다. 모든 새 피격 후보는 맞는 순간부터 재생하며 발사·비행음은 없다. 오리는 한 번 맞을 때 두 번 꽥꽥 운다. 확대 세 원본 WAV·반복 WAV는 3차 파일과 동일 바이트다. 기절 PNG·별·링·GIF는 2차 링크로 함께 검토한다.

- 오리: Breviceps의 Cartoon - Duck Quack 공개 HQ MP3를 편집. 원래 꽥 음색을 유지하고 두 울음의 속도·간격·두 번째 음량을 비교한다.
- 대포: EZduzziteh의 explosion2와 Thimras의 cannon_hit_1 앞부분을 편집. 시작부터 폭발하며 A는 짧은 펑, B는 낮은 울림, C는 빠르고 밝은 팡이다.
- 나머지: Kenney Impact Sounds의 실제 타격·재질 샘플을 자르고 고정 주파수의 짧은 공명을 겹친다. 상승 멜로디·발사 휘슬은 사용하지 않는다.

출처·저자·CC0 라이선스·원본 다운로드 URL·SHA-256은 [소스 기록](sources/manifest.json)에 보존했다. Kenney 배포본의 `License.txt`도 줄바꿈·끝 공백만 정리해 포함한다. 원본 압축 음원과 48kHz mono PCM16 디코딩 WAV를 함께 두어 네트워크 없이 후보를 재생성할 수 있다. FFmpeg 7.1(imageio-ffmpeg 0.6.0)으로 변환했으며 해당 도구는 앱 의존성에 추가하지 않았다.

## 검토 방법

종류별 비교는 A → B → C, 확대는 C-1 → C-2 → C-3 순이다. 한 번·세 번 재생, WAV 다운로드, 종류별 후보 선택과 피드백 모으기를 제공한다. 새 버튼을 누르면 이전 재생을 중단한다. 숨김·페이지 이탈·Escape도 정지한다. 상단 피격/확대 표시는 청취용 시점 안내이며 앱 장면의 동기화 검증을 대신하지 않는다.

일반 피격 반복은 0.5초, 오리는 두 울음을 온전히 비교하기 위해 0.9초, 확대는 1초 간격이다. 이는 검토 파일의 배치 간격이며 앱의 cooldown이나 동시 재생 정책 변경이 아니다. 피격음은 0.12~0.77초. 모든 후보의 peak는 -14dBFS 이하이며 강한 시작음을 유지해 재질별 평균 음량은 다르다. 반복·비교 파일은 원본 PCM을 그대로 배치한다.

## 검증

```sh
python3 docs/reviews/character-feedback/round-4/generate_audio.py
python3 docs/reviews/character-feedback/round-4/verify_review.py
node --check docs/reviews/character-feedback/round-4/review.js
```

검증 통과: 후보 27개·8개 실제 투척물 ID·WAV 63개, 개별/반복/비교 PCM과 해시, 음량 상한·무음 경계·충돌 시작 8ms 이내·오리 외 앞 80ms 에너지가 마지막 80ms보다 큼, 확대 원본 보존·네 음 길이, 출처 파일 해시, 정적 HTML 링크, JavaScript 문법. 로컬 HTTP 페이지와 오리·대포 음원 응답 200 확인. 연결된 브라우저가 없어 실제 브라우저 조작·청감 검증은 수행하지 않았다. 사용자 청취·선택이 필요하다.

기존 말랑공 C 승인은 이전 파일에 대한 기록이며 4차 후보에 승계하지 않는다. 새 피격음 전부, 확대 최종 파일과 기절 시각의 승인을 받은 뒤 별도 macOS 브랜치에서 직배포판에 연결한다.
