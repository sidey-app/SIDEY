# 캐릭터 피드백 3차 검토

확대 C의 각 음이 너무 짧다는 피드백을 반영하고 나머지 모든 투척물의 효과음을 제안한다. `index.html`에서 종류별 원음·3회 반복·후보 순서 비교를 재생하고 선택을 한 번에 정리할 수 있다.

## 구성

- 말랑공: 사용자가 선택한 2차 C를 바이트·음량 그대로 유지한다. 해당 파일의 선택을 승인 기록에 반영하며 다시 선택을 요구하지 않는다.
- 확대 C-1: 4음 × 90ms = 0.36초.
- 확대 C-2: 4음 × 120ms = 0.48초.
- 확대 C-3: 3음 × 110ms + 마지막 음 290ms = 0.62초.
- 확대는 기존 C의 네 주파수·사각파 배음 조합을 유지하고 무음 간격을 줄였다. 기존 C의 음 하나는 60ms였다. 모두 기존 0.8초 확대·복귀 연출 안에 끝난다.
- 미니 파프리카·바나나·먼지목욕 모래주머니·별빛 구슬·통통 하트·미니 대포·삑삑 오리는 각각 A/B/C 세 후보다.
- 총 25개 후보: 선택된 말랑공 1개 + 새 확대 3개 + 새 투척물 21개. 원음 25개·반복 25개·종류별 비교 8개로 WAV 58개를 제공한다.
- 피격 반복은 0.5초, 확대 반복은 1초 간격이다. 길어진 확대음을 0.5초마다 겹치거나 덮어쓰지 않는다.
- 기절 PNG·GIF는 2차의 별·링을 그대로 참조한다. 시각 최종 승인은 별도로 대기한다.

## 승인 상태

말랑공 `hit-c-v2`만 사용자의 선택으로 고정했다. 확대는 C의 방향을 선택했지만 새로운 길이 세 후보 중 선택은 아직 대기다. 나머지 7종도 선택·승인 대기다. 앱 코드·리소스·설정은 변경하지 않는다.

## 재현·검증

저장소 루트에서 각각 실행한다.

```sh
python3 docs/reviews/character-feedback/round-3/generate_audio.py
python3 docs/reviews/character-feedback/round-3/verify_review.py
node --check docs/reviews/character-feedback/round-3/review.js
node --check docs/reviews/character-feedback/round-3/review-data.js
```

외부 녹음이나 라이브러리 없이 Python 표준 라이브러리로 합성했다. 피격별 재질은 모달 타격·고무 배음·필터된 잡음·작은 종·공기 충격·고무 오리 배음으로 구분했다. 짧은 타격·모래 질감의 피크를 부드럽게 제한해 비교 음량을 맞췄으며 선택된 말랑공과 확대 C 음색에는 이 처리를 추가하지 않았다. peak는 -14dBFS 이하, RMS는 약 -25.4~-22.7dBFS이며 48kHz/16bit/mono WAV를 사용한다.

검증은 실제 PCM의 길이·끝점·RMS·peak·DC, 각 확대음의 실제 주파수·유지 길이, 원본 말랑공 파일 일치, 반복·비교 WAV의 무음과 순서, 전체 카탈로그 8종 커버리지·후보 수·승인 상태·해시·HTML 링크·JS 구문을 포함한다. 음색 선호도와 최종 승인은 사용자의 실제 청취로 결정한다. 앱 테스트·빌드·부하 검증은 승인 후 구현 단계에 남아 있다.

위 파일·음원 검증 및 JS 구문 검사는 통과했고 localhost 검토 페이지의 HTTP 200을 확인했다. 연결된 브라우저가 없어 실제 브라우저 클릭·청취 검증은 수행하지 못했다.
