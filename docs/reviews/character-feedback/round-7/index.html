대기

재생할 후보를 골라 주세요.

종류별 비교 버튼은 A → B → C 순서로 한 번씩 재생합니다. 반복 듣기는 하트·오리·기존 피격음 0.5초, 대포·채팅음 1초 간격이며 다른 재생을 누르면 이전 소리는 멈춥니다.

피격음은 맞는 순간, 채팅음은 말풍선이 나타나는 순간의 소리입니다. 하트는 한 번 맞으면 팝 한 번입니다. ‘한 번 듣기’는 이벤트 1회, ‘피격 3회 듣기’와 ‘채팅 3개 듣기’는 각각 별도 이벤트 3회를 비교합니다.

하트와 채팅음은 각각 A/B/C 중에서 골라 주세요. 나머지 일곱 소리는 선택한 파일·음량 그대로 유지했습니다. 후보 선택이 서버로 전송되거나 자동 승인되지는 않습니다.
