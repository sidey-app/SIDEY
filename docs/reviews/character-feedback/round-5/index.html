대기

재생할 후보를 골라 주세요.

종류별 비교 버튼은 A → B → C 순서로 한 번씩 재생합니다. 반복 듣기는 오리·기존 피격음 0.5초, 대포 1초 간격이며 다른 재생을 누르면 이전 소리는 멈춥니다.

모든 피격 후보는 맞는 순간부터 재생하는 소리입니다. 오리는 한 번 맞을 때 한 번만 웁니다. ‘3회 피격 듣기’는 서로 다른 세 번의 피격을 비교하는 버튼입니다. 대포 1초 반복 간격은 청취용이며 앱 쿨타임을 변경하지 않습니다.
