오리는 Breviceps의 단일 quack 원본을 한 번만 사용한다. A는 원래 높이, B는 약간 높고 짧게, C는 약간 낮고 길게 편집했다. ‘3회 피격 듣기’는 0.5초 간격으로 독립된 세 번의 피격을 재생한다. 한 번 맞는 상황에서 울음을 반복하지 않는다.

대포는 Thimras의 cannon_hit_1에서 시작하는 폭발 부분을 사용하고 세 단계 저역 통과 필터로 거친 고역을 줄였다. 4차의 explosion2 혼합·고역 타격 샘플·tanh 포화를 사용하지 않는다. 동시에 시작하는 낮은 공명을 더하고 선형 음량 조절과 끝 fade만 적용한다. A 0.48초, B 0.66초, C 0.40초이며 청취 반복 간격은 1초다. 발사·비행음은 없고 실제 충돌에서 시작한다.

기존 선택 다섯 개와 미선택 하트는 단일·반복 WAV를 동일 바이트로 복사했다. 확대 동작과 기절은 유지하며 폐기한 것은 확대 효과음이다. 기절 PNG는 승인된 V2 링크를 그대로 제공한다.

음원 출처·저자·CC0 라이선스·원본 해시는 [4차 소스 기록](../round-4/sources/manifest.json)에 보존되어 있다. 새 오리·대포는 해당 폴더의 디코딩 WAV를 읽어 재현하므로 새 다운로드가 필요 없다. `generate_audio.py`는 4차의 파일 처리 함수를 재사용하지만 4차 출력 파일을 덮어쓰지 않는다.

검증: 새 6개 + 선택 원본 5개 + 하트 3개, WAV 총 31개. 선택·승인 상태, 원본 바이트 보존, 단일 quack 길이·샘플 재현, -14dBFS 이하 peak·DC·fade 경계, 반복·비교 PCM과 해시, 확대음 제외, HTML 링크 및 JavaScript 문법 확인. 로컬 페이지·오리·대포 WAV 응답 200. 실제 청감과 브라우저 조작 검증은 사용자 검토 단계다.

```sh
python3 docs/reviews/character-feedback/round-5/generate_audio.py
python3 docs/reviews/character-feedback/round-5/verify_review.py
node --check docs/reviews/character-feedback/round-5/review.js
```
