# 종료된 제품 운영 기록

현재 동작은 [제품 기획서](../PRODUCT_SPEC.md), 확정 사항과 변경 이유는 [결정 기록](../DECISIONS.md)을 따른다. 아래 내용은 과거 후보·실험·작업 경과이며 현재 정책을 덮어쓰지 않는다.

## 상품 등록·업로드 비교 기록

2026-09-12 App Store 1.2.1 build 30은 전송 후 Apple 처리 단계에서 오류 91109로 실패했다. 업로드한 아카이브의 `pixel_hamster.png`에 `com.apple.quarantine` 1건이 남았고 원본과 파일 해시는 일치했다. App Store 타깃의 리소스 복사 후 서명 전 단계에서 격리 속성을 제거하고 CLI archive 검사에서 잔존 속성을 거부한다. 동등 기능 마케팅 버전 1.2.1을 유지하며 재빌드 후보 번호는 31로 올린다. 직배포 build 29·Windows·공개 릴리스 메타데이터는 유지한다. 새 아카이브 검증과 Apple 재업로드·처리 성공·심사 제출은 구분한다.

2026-09-12 사용자 요청으로 원숭이 현재 Apple 판매 ID를 `character_monkey_solo_4`로 변경해 비교한다. `_solo_2` 재연결 결정을 대체하며 `_solo_3`·`_solo_2`·`_solo`·`character_monkey`는 복원·거래 검증용으로 유지한다. 다른 상품·가격·권리는 유지하며 판매 상품 24종, Apple 검증 ID 34개다. 기존 브랜치에서 로컬 후보를 준비하고 Connect 등록·원격 서버 배포·실제 조회 결과는 별도로 확인한다. 재등록은 미조회 원인의 확정이나 해결 보장이 아니다.

2026-09-12 조개·돼지고기의 `_2`가 같은 앱 프로세스에서 정상 조회된 후, 원숭이도 기존 `character_monkey_solo_2`로 다시 연결해 비교한다. `_solo_3`은 복원·거래 검증용으로 보존하며 나무·조개·돼지고기 ID, 가격과 권리는 유지한다. 현재 원숭이 판매 ID는 `_solo_2`이며 앞선 `_solo_3` 비교 결정을 대체한다. 원격 DB·verifier 배포 및 실제 원숭이 조회 성공은 별도 확인한다.

2026-09-12 원숭이 단독 재등록 비교를 승인했다. 현재 원숭이 Apple 판매 ID만 `character_monkey_solo_3`으로 변경하고 `_solo_2`·`_solo`·기존 포함 상품 `character_monkey`는 복원·거래 검증용으로 보존한다. 나무 `character_tree_2`, 조개 `throwable_clam_2`, 돼지고기 `throwable_pork_2`와 가격·내부 상품 ID·권리는 유지한다. 상품은 24종, Apple 검증 ID는 33개다. 기존 작업 브랜치에서 로컬 비교 후보를 준비하며 신규 Connect 등록과 실제 조회 성공은 별도 확인한다. 재등록 효과나 미조회 원인이 확정된 것은 아니다.

2026-09-12 macOS 직배포판과 App Store판의 상점 캐릭터 7종 소개를 짧고 귀여운 이야기로 통일한다. 캐릭터 상세 상단에는 제목만 두고 소개는 왼쪽 캐릭터 구매 카드의 이름 아래에 표시한다. 나무의 우클릭 정지·재개 안내는 미리보기 무대 안쪽 왼쪽 위로 옮겨 유지한다. 캐릭터 소개는 번들 카탈로그를 우선해 이전 서버 문구가 덮어쓰지 않게 하며 서버 카탈로그도 같은 문구로 맞춘다. 투척물 소개·상품 ID·가격·소유권·구매 동작은 유지한다.

2026-09-12 상점 표현 수정: 상세창은 실제 내용 높이에 맞춰 하단 빈 공간을 줄이고 긴 내용만 스크롤한다. 애착 물건의 사용 범위 안내와 구매 카드의 부가 사용 안내는 빼고, 물건마다 짧은 농담이 담긴 소개를 사용한다. 돼지고기는 `찰진 촵! 근데 옆집 꿀꿀이가 며칠 전부터 안 보이던데…?`로 표시한다. 별도 판매 표시는 유지하며 사용 가능 캐릭터·소유권·가격은 변경하지 않는다.

2026-09-12 미리보기 조작 수정: 캐릭터 상세의 상대 캐릭터를 클릭하면 해당 애착 물건을 로컬에서 던진다. 별도 체험 버튼·체험 배지와 공통 분리 구매 안내 문구는 제거하고 애착 물건 카드의 `별도 판매` 표시는 유지한다. 음소거 버튼은 캐릭터·투척물 미리보기 무대 안쪽 우상단에 둔다. 나무 상세에서는 `나무를 우클릭하면 멈추고, 다시 우클릭하면 걸어요.`를 무대 위에 상시 표시한다. 실제 장착·소유권·공통 기본 말랑공 정책은 변경하지 않는다.

2026-09-12 확정: 상품 분류명은 **애착 물건**이다. 유료 캐릭터 7종의 고유 투척물을 별도 비소모성 상품으로 분리하고 모든 캐릭터에서 사용한다. A안(한 무대 아래 캐릭터·애착 물건 카드 두 개)을 구현하며 별도 판매를 상시 표시한다. 투척물 탭에도 같은 상품을 노출한다. 기본 투척물은 모든 캐릭터 공통 말랑공이다. 새 애착 물건은 직배포 990원 / 한국 App Store 1,100원, 말풍선은 1,900원 / 2,200원이며 개별 지정 예외 가격은 유지한다. 기존 캐릭터 보유자의 포함 물건 권리는 지급 출처에 연결해 보존하고 환불·회수 시 해당 출처만 회수한다. 이미 판매된 캐릭터 4종의 기존 App Store ID는 포함 상품 복원을 위해 보존하고 `_solo` 단품 ID를 추가한다. 신규 3종은 미출시 ID를 유지한다. 판매 카탈로그는 24종, App Store 검증 ID는 과거 4종을 포함한 28개다. 앞선 캐릭터에 고유 투척물 포함 결정을 신규 단품 구매에 한해 대체한다. macOS 두 버전과 공통 서버를 구현하며 Windows·공개 웹·실판매 활성화·심사 제출·릴리스는 후속이다. 결정 기준 카탈로그는 `assets/v1/commerce-catalog.json`이며 원격 등록·배포와 로컬 검증 상태를 구분한다.

## 효과음·기절 후보 제작과 승인 과정

### 4.4.1 직배포판 효과음·기절 — 승인 선행, 구현 예정

사용자는 하트 7차 B(팝 한 번)를 최종 선택하고 채팅 말풍선 소리를 폐기했다. 승인된 피격음 8종만 기절과 함께 macOS 직배포판에 연결한다. 확대·채팅음은 모두 제외한다. 기본 ON 소리 스위치·직배포 schema 9·4개 동시 재생·80ms 시작 제한은 유지한다. 사용자가 직접 때려볼 수 있도록 Debug 직배포 전용 로컬 테스트 방과 상대 캐릭터 한 명, 8종 투척물 선택을 준비하고 Xcode를 연다. 이 테스트 방은 서버 계정·실제 방을 생성하지 않는다. 최종 WAV와 SHA-256은 audio-approval.json에 기록한다.

7차 수정: 사용자는 하트를 한 번 맞을 때 팝 한 번으로 명확히 정정했다. 이전 6차의 두 팝은 어시스턴트의 해석 오류이며 폐기한다. 기존 세 음색 각각의 첫 팝만 남기고 음량을 유지한다. 새 채팅 말풍선이 올라왔을 때의 소리도 서로 다른 3개 시안으로 추가 요청했다. 이번 단계는 음원 방향 검토이며 적용 전 승인을 받는다. 오리 B·대포 C를 포함한 기존 7종 선택과 확대음 폐기는 유지한다.

6차 음원 결정: 사용자가 오리 5차 B·대포 5차 C를 선택했다. 이전에 고른 다섯 피격음과 함께 원본·음량 그대로 확정한다. 하트만 입술을 터뜨리는 `뾲뾲` 질감으로 다시 제작하며, 한 번 피격에 짧은 팝 두 번인 3개 후보를 제출한다. 새 하트는 적용 전 선택·승인을 받는다. 확대음 폐기는 유지한다.

2026-09-10 5차 음원 결정: 확대 효과음 기획을 폐기한다. 캐릭터 확대 동작 자체는 유지한다. 말랑공 A·미니 파프리카 C·바나나 B·먼지목욕 모래주머니 C·별빛 구슬 B는 4차 원본과 음량 그대로 선택 확정한다. 통통 하트는 미선택이며 수정 요청이 없어 4차 후보를 유지한다. 오리와 대포만 각 3안으로 재제작한다. 오리는 한 번 맞을 때 꽥 한 번만, 대포는 깨지는 질감 대신 낮은 울림의 충돌 폭발음으로 다듬는다. 새 후보의 앱 적용 승인은 별도로 받는다.

macOS 직배포판 프로필의 캐릭터·말풍선·투척물 선택 표시는 기존 캐릭터 기준인 보라색(RGB 0.45/0.49/0.85) 3pt 테두리·동일한 원형 체크·선택 배경으로 통일한다. 장착 요청 중 스피너와 확정 선택 구분, 키보드 focus는 유지한다. App Store·Windows 구현은 이번 수정 대상이 아니다.

기절 선행 구현과 승인된 피격음 8종·소리 설정·선택 테두리 통일을 `macos/v1.1.0-release`에 통합했다. 하트는 7차 B의 단일 팝이며 채팅·확대음은 폐기했다. Debug 전용 `SIDEYFeedback` scheme은 로그인 없이 나와 콩이가 있는 로컬 검증 방을 연다. 이 방은 Release에 포함되지 않는다.

2026-09-10 사용자가 “효과음 내일 이어서 … 우선 기절쪽만 구현”을 지시했다. 이를 현재 별·링 V2와 기존 수면 모션을 사용하는 기절 구현의 승인으로 기록한다. 기절을 효과음과 분리해 macOS 직배포판에 먼저 구현한다. 10초 내 10회·6초 기절·보호 시간 없음은 유지한다. 효과음·소리 설정·설정 schema 변경은 보류하며 기절 구현에 포함하지 않는다. 앞선 음원·시각 일괄 승인 후 구현 순서보다 이번 분리 지시가 우선한다.

4차 검토는 말랑공을 포함한 피격음 8종 전체를 각 3안으로 다시 제작한다. 시작점은 실제 충돌이며 발사·비행음은 없다. 오리는 꽥꽥 울음, 대포는 충돌 폭발 펑으로 만들고, 다른 물체도 짧은 접촉·타격음을 중심으로 구분한다. 외부 CC0 샘플을 편집한 후보는 원본·저자·출처·라이선스·SHA-256을 검토 폴더에 기록한다. 확대 C 기반 세 WAV와 기절 별·링 V2는 그대로 보존한다. 오리의 두 울음은 한 번의 피격음이며, 검토 페이지에서만 0.9초 간격으로 반복한다. 이 청취 간격은 앱의 투척 cooldown·80ms 음원 시작 제한을 바꾸지 않는다. 기존 말랑공 C 선택을 새 음원의 승인으로 승계하지 않는다.

이전 3차 검토에서는 사용자가 선택한 말랑공 2차 C를 동일 바이트·음량으로 유지한다. 확대도 2차 C의 8비트 방향을 선택했으나 각 음이 너무 짧다는 피드백으로, 90ms씩 4음·120ms씩 4음·110ms씩 3음과 290ms 마지막 음의 후보 세 가지를 제공한다. 총 길이는 0.36·0.48·0.62초로 모두 기존 0.8초 확대·복귀 안에 끝난다. 음이 겹치지 않게 검토용 확대 반복은 기존 cooldown과 같은 1초 간격으로 한다. 미니 파프리카·바나나·먼지목욕 모래주머니·별빛 구슬·통통 하트·미니 대포·삑삑 오리도 각각 세 후보를 제공한다. 기절의 별·링은 2차 시안을 유지하며 최종 시각 승인은 별도로 받는다.

2차 검토에서는 1차의 별 모양·위치·회전 속도를 유지하고 동일 궤도에 1 논리 픽셀 두께의 타원 링을 추가한다. 말랑공은 짧게 튀어 오르는 음높이와 발랄한 탄성으로 수정하고, 확대음은 풍선 장난감·반짝이는 마법 종소리·8비트 레벨업의 세 가지 독립적인 음색 방향을 먼저 제안한다. 사용자가 방향을 선택한 뒤 길이·음색을 다듬고 최종 음원과 링 PNG·합성 동작을 다시 승인받는다. 1차 자료는 덮어쓰지 않는다.

이번 변경은 macOS 직배포판과 Sidey-dev 검증에 한정한다. App Store판·Windows·공개 웹에는 구현하지 않는다. 효과음 WAV와 기절 PNG·동작 시안을 같은 검토 단계에서 제출하고, 각각의 명시적 승인 전에는 앱에 적용하지 않는다. 기절의 몸통은 기존 offline 2프레임을 그대로 렌더링하고 별만 별도 공통 픽셀 에셋으로 만든다. 승인 후보·합성 검토 PNG·GIF는 승인 원본과 앱 번들에서 분리한다. 단계별 작업 상태는 [작업 기록](../reviews/character-feedback/PLAN.md)을 참조한다.

- 투척물별 피격음 8종을 사용하며 확대음은 폐기했다. 채팅 말풍선 소리도 폐기했다. 시각 효과와 동일한 투척물 ID 해석·fallback을 사용하며 실제 충돌에서 한 번 재생한다. 발사·비행·확대·축소·기절·회복음은 추가하지 않는다.
- 설정의 `표시` 다음에 `소리 / 캐릭터 효과음` 스위치를 둔다. 설명은 `현재 그룹에서 캐릭터가 맞을 때 효과음을 재생합니다.`다. 신규·기존 사용자 모두 ON, 로컬 저장·즉시 적용·OFF 시 현재 재생 중단으로 정한다. 조용히 모드와 독립적이며 직배포판에만 설정 schema 9와 `characterSoundEffectsEnabled`를 추가한다. App Store판 schema 8은 유지한다.
- 현재 표시된 그룹의 모든 캐릭터 효과음을 재생한다. 동시 최대 4개, 시작 간격 최소 80ms를 초기값으로 두고 초과한 소리는 대기열 없이 생략한다. 시각 효과와 피격 누적은 생략하지 않는다. 숨김·잠금·절전·그룹 전환 시 재생을 중단하며 복귀 뒤 재생하지 않는다. 상점의 직접 조작은 설정을 따르고 자동 반복은 무음이다.
- 대상 UUID별로 정확히 10초 전까지 포함한 최근 충돌을 합산하고 중복 이벤트는 한 번만 센다. 10번째 충돌에서 일반 hit 대신 즉시 6초 기절로 전환하고 누적을 비운다. 기절 중 추가 충돌은 충돌 효과·피격음만 재생하며 연장·적립하지 않는다. 회복 시각부터 보호 시간 없이 새 피격을 누적한다.
- 화면에 표시된 모든 Presence 상태가 대상이다. 기절은 Presence와 독립적이며 상태 점·색상·닉네임·채팅·타이핑을 유지한다. 기절 동안 산책·Zzz·ambient sparkle을 멈추고 웅크린 수면에 노란 별 3개를 표시한다. 별은 1.2초 타원 회전 시안으로 검토하며 최종 배치·속도는 시각 승인으로 고정한다. 모션 감소에서는 정적 포즈와 별을 표시한다.
- 자기 캐릭터의 확대·던지기는 재생·쿨타임 소비·RPC 전에 차단한다. 채팅과 이미 발사된 투척물, 유효한 원격 투척은 계속 처리한다. 기절한 몸동작은 수면을 우선한다. 회복 시 당시 Presence 모션으로 돌아가고 발 위치·기존 산책 목적지는 보존한다. 확대 도중 기절하면 기본 크기로 복귀한다.
- 외형 변경은 누적을 유지한다. 방 전환·대상 제거·오버레이 해체·잠금·연결 재수립은 임시 상태를 정리한다. 로컬 충돌 판정이라 화면별 시점 차이가 가능하며 구버전·Windows의 조작까지 서버에서 차단하지 않는다.
- 실제 충돌 이벤트와 기절 판정은 장면이 소유하고 오디오 서비스는 재생·자원·출력 장치 변경을 소유한다. API·Broadcast payload·Presence는 변경하지 않는다. `APP_STORE` 컴파일 조건과 직배포 전용 리소스 소속으로 신규 코드·설정·WAV·별 PNG를 분리한다.
