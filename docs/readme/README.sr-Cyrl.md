## О апликацији

SIDEY је апликација за размену порука за macOS и Windows. Разговарате са пријатељима преко 2D пикселских животиња на ивици екрана. Сваки лик представља стварног пријатеља и приказује његов статус и кратке поруке док радите или се одмарате.

![SIDEY на macOS-у: пикселске животиње размењују поруке у дну екрана.](assets/sidey-overlay-preview.png)

- Наставите свој посао: користите апликације иза SIDEY-ја као и обично.
- Погледајте пријатеље: ликови ходају, дремају или спавају и тако показују ко је на мрежи.
- Напишите нешто: отворите SIDEY да пошаљете кратку поруку или се нашалите са пријатељима.
