## 紹介

SIDEYは、画面の端にいる2Dピクセル動物を通じて友だちと会話できる、macOS・Windows向けのデスクトップメッセンジャーです。キャラクターの一匹一匹が実際の友だちを表し、作業中や休憩中にも友だちの様子や短いメッセージを見られます。

![macOSでのSIDEYの表示例 — 作業画面の下で、ピクセル動物の友だちがメッセージをやり取りしています。](sidey-overlay-preview.png)

- **作業はそのまま:** SIDEYが表示されていても、背後のアプリをいつもどおりクリックして使えます。
- **友だちの今をちらり:** 歩いたり、うとうとしたり、眠ったりする姿から、友だちが今オンラインかどうかがわかります。
- **思いついたらひとこと:** SIDEYを開いて短いメッセージを送ったり、ちょっとしたいたずらをし合ったりできます。

## インストール

### macOS

**動作環境:** macOS 26以降 · Apple Silicon。Intel Macには対応していません。

<details>
  <summary><strong>Mac App Storeからダウンロード</strong></summary>
  <br/>
  <p>Mac App Storeから簡単にインストールできます:</p>
  <p>
    <a href="https://apps.apple.com/kr/app/sidey/id6808528060">
      <img src="mac-app-store.ja.svg" height="48" alt="Mac App StoreでSIDEYをダウンロード">
    </a>
  </p>
  <p>Appleの審査があるため、アップデートの公開が遅れる場合があります。</p>
</details>

### Windows

**動作環境:** Windows 10 1809以降 · x64。

<details>
  <summary><strong>GitHubから.exeをダウンロード</strong></summary>
  <br/>

  [SIDEYのGitHubリリース](https://github.com/sidey-app/SIDEY/releases)ページを開き、下へスクロールして**Assets**からお使いの環境に合ったインストールファイルをダウンロードすると、インストールできます。

</details>
