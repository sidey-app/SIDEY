## Über SIDEY

SIDEY ist ein Desktop-Messenger für macOS und Windows. Du chattest mit Freunden über 2D-Pixeltiere am Bildschirmrand. Jede Figur steht für einen echten Freund und zeigt seinen Status und kurze Nachrichten, während du arbeitest oder eine Pause machst.

![SIDEY unter macOS: Pixeltiere tauschen Nachrichten am unteren Bildschirmrand aus.](assets/sidey-overlay-preview.png)

- Mach einfach weiter: Nutze die Anwendungen hinter SIDEY wie gewohnt.
- Schau nach deinen Freunden: Ob die Figuren laufen, dösen oder schlafen, zeigt dir, wer gerade online ist.
- Schreib eine Kleinigkeit: Öffne SIDEY, um eine kurze Nachricht zu senden oder gemeinsam herumzualbern.
