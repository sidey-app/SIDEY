## 簡介

SIDEY 是一款適用於 macOS 和 Windows 的桌面聊天應用程式，讓你透過螢幕邊緣的 2D 像素小動物與朋友聊天。每個角色都代表一位真實的朋友，工作或休息時，你都能看到朋友的狀態和簡短訊息。

![SIDEY 在 macOS 上的使用範例：像素小動物朋友們在工作畫面的下方互傳訊息。](sidey-overlay-preview.png)

- **手邊的事照常做：** SIDEY 顯示在螢幕上時，你仍然可以像平常一樣點選和使用後方的應用程式。
- **瞧瞧朋友在不在：** 看看角色是在散步、打盹還是睡覺，就能知道朋友現在是否在線上。
- **想到就聊一句：** 打開 SIDEY，傳則簡短訊息，或和朋友互相逗趣。

## 安裝

### macOS

**系統需求：** macOS 26 或以上版本 · Apple Silicon。不支援 Intel Mac。

<details>
  <summary><strong>從 Mac App Store 下載</strong></summary>
  <br/>
  <p>透過 Mac App Store 就能輕鬆安裝：</p>
  <p>
    <a href="https://apps.apple.com/kr/app/sidey/id6808528060">
      <img src="mac-app-store.zh-Hant.svg" height="48" alt="在 Mac App Store 下載 SIDEY">
    </a>
  </p>
  <p>由於需要經過 Apple 審核，更新可能會晚一些推出。</p>
</details>

### Windows

**系統需求：** Windows 10 1809 或以上版本 · x64。

<details>
  <summary><strong>從 GitHub 下載 .exe 檔案</strong></summary>
  <br/>

  前往 [SIDEY GitHub Releases](https://github.com/sidey-app/SIDEY/releases) 頁面，向下捲動至 **Assets**，下載適合你裝置的安裝檔並安裝。

</details>
