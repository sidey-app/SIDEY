## 簡介

SIDEY 是一款適用於 macOS 和 Windows 的桌面聊天應用程式，讓你透過螢幕邊緣的 2D 像素小動物與朋友聊天。每個角色都代表一位真實的朋友，工作或休息時，你都能看到朋友的狀態和簡短訊息。

![SIDEY 在 macOS 上的使用範例：像素小動物朋友們在工作畫面的下方互傳訊息。](assets/sidey-overlay-preview.png)

- **手邊的事照常做：** SIDEY 顯示在螢幕上時，你仍然可以像平常一樣點選和使用後方的應用程式。
- **瞧瞧朋友在不在：** 看看角色是在散步、打盹還是睡覺，就能知道朋友現在是否在線上。
- **想到就聊一句：** 打開 SIDEY，傳則簡短訊息，或和朋友互相逗趣。
