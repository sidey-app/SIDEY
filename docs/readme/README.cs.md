## O aplikaci

SIDEY je desktopová aplikace pro zasílání zpráv pro macOS a Windows. S přáteli si povídáte prostřednictvím 2D pixelových zvířátek na okraji obrazovky. Každá postavička představuje skutečného přítele a ukazuje jeho stav a krátké zprávy, zatímco pracujete nebo odpočíváte.

![SIDEY na macOS: pixelová zvířátka si vyměňují zprávy ve spodní části obrazovky.](assets/sidey-overlay-preview.png)

- Pokračujte v práci: aplikace za SIDEY můžete používat jako obvykle.
- Podívejte se na přátele: chůze, podřimování a spánek postaviček ukazují, kdo je právě online.
- Napište pár slov: otevřete SIDEY a pošlete krátkou zprávu nebo si s přáteli zažertujte.
