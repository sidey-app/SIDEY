## O aplikacji

SIDEY to komunikator na macOS i Windows. Rozmawiasz ze znajomymi za pośrednictwem pikselowych zwierzątek 2D na krawędzi ekranu. Każda postać reprezentuje prawdziwego znajomego i pokazuje jego status oraz krótkie wiadomości, gdy pracujesz lub odpoczywasz.

![SIDEY na macOS: pikselowe zwierzątka wymieniają wiadomości u dołu ekranu.](assets/sidey-overlay-preview.png)

- Rób dalej swoje: korzystaj z aplikacji za SIDEY tak jak zwykle.
- Zobacz, co u znajomych: postacie chodzą, drzemią lub śpią, pokazując, kto jest online.
- Napisz kilka słów: otwórz SIDEY, aby wysłać krótką wiadomość lub pożartować ze znajomymi.
