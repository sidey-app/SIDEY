## Acerca de SIDEY

SIDEY es una aplicación de mensajería de escritorio para macOS y Windows. Habla con tus amigos a través de animales de píxeles 2D en el borde de la pantalla. Cada personaje representa a un amigo real y muestra su estado y mensajes breves mientras trabajas o descansas.

![SIDEY en macOS: pequeños animales de píxeles intercambian mensajes en la parte inferior de la pantalla.](assets/sidey-overlay-preview.png)

- Sigue con lo tuyo: utiliza las aplicaciones que están detrás de SIDEY como siempre.
- Mira cómo están tus amigos: sus movimientos al caminar, dormitar o dormir te muestran si están conectados.
- Di algo cuando quieras: abre SIDEY para enviar un mensaje breve o compartir un momento divertido.

## Errores y sugerencias de funciones

Si encuentras un error o quieres proponer una función, abre una incidencia siguiendo las plantillas de [GitHub Issues](https://github.com/sidey-app/SIDEY/issues).
