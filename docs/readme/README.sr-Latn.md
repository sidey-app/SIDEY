## O aplikaciji

SIDEY je aplikacija za razmenu poruka za macOS i Windows. Razgovarate sa prijateljima preko 2D pikselskih životinja na ivici ekrana. Svaki lik predstavlja stvarnog prijatelja i prikazuje njegov status i kratke poruke dok radite ili se odmarate.

![SIDEY na macOS-u: pikselske životinje razmenjuju poruke u dnu ekrana.](assets/sidey-overlay-preview.png)

- Nastavite svoj posao: koristite aplikacije iza SIDEY-ja kao i obično.
- Pogledajte prijatelje: likovi hodaju, dremaju ili spavaju i tako pokazuju ko je na mreži.
- Napišite nešto: otvorite SIDEY da pošaljete kratku poruku ili se našalite sa prijateljima.
