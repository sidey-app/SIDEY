## Sobre o SIDEY

O SIDEY é um aplicativo de mensagens para macOS e Windows. Converse com amigos por meio de animais em pixels 2D na borda da tela. Cada personagem representa um amigo real e mostra seu status e mensagens curtas enquanto você trabalha ou descansa.

![SIDEY no macOS: animais em pixels trocam mensagens na parte inferior da tela.](assets/sidey-overlay-preview.png)

- Continue o que está fazendo: use normalmente os aplicativos atrás do SIDEY.
- Veja como seus amigos estão: os personagens caminham, cochilam ou dormem para mostrar quem está online.
- Mande uma mensagem: abra o SIDEY para enviar uma mensagem curta ou compartilhar um momento divertido.
