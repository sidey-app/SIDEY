## Over SIDEY

SIDEY is een desktopmessenger voor macOS en Windows. Je praat met vrienden via 2D-pixeldieren aan de rand van je scherm. Elk personage stelt een echte vriend voor en toont diens status en korte berichten terwijl je werkt of ontspant.

![SIDEY op macOS: pixeldieren wisselen berichten uit onderaan het scherm.](assets/sidey-overlay-preview.png)

- Ga verder met je werk: gebruik de apps achter SIDEY zoals je gewend bent.
- Kijk hoe het met je vrienden gaat: de personages lopen, dommelen of slapen om te laten zien wie online is.
- Zeg even iets: open SIDEY om een kort bericht te sturen of samen wat plezier te maken.
