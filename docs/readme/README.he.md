## על SIDEY

SIDEY היא אפליקציית הודעות למחשב עבור macOS ו-Windows. אפשר לשוחח עם חברים באמצעות חיות פיקסלים דו-ממדיות בשולי המסך. כל דמות מייצגת חבר אמיתי ומציגה את המצב שלו ואת ההודעות הקצרות שלו בזמן שאתם עובדים או נחים.

![SIDEY ב-macOS: חיות פיקסלים מחליפות הודעות בתחתית המסך.](assets/sidey-overlay-preview.png)

- ממשיכים בעבודה: אפשר להשתמש באפליקציות שמאחורי SIDEY כרגיל.
- מציצים לשלומם של החברים: הדמויות הולכות, מנמנמות או ישנות כדי להראות מי מחובר.
- אומרים כמה מילים: פתחו את SIDEY כדי לשלוח הודעה קצרה או להשתעשע עם החברים.
