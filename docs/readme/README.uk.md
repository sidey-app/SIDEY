## Про застосунок

SIDEY — месенджер для macOS і Windows, у якому ви спілкуєтеся з друзями через двовимірних піксельних звірят біля краю екрана. Кожен персонаж представляє справжнього друга: поки ви працюєте чи відпочиваєте, можна бачити його статус і короткі повідомлення.

![Приклад SIDEY на macOS: піксельні звірята обмінюються повідомленнями внизу робочого екрана.](sidey-overlay-preview.png)

- **Займайтеся своїми справами:** навіть коли SIDEY на екрані, ви можете як завжди натискати на елементи застосунків під ним і працювати в них.
- **Дізнавайтеся, як там друзі:** персонажі гуляють, дрімають і сплять — за їхньою поведінкою видно, хто зараз у мережі.
- **Напишіть, коли заманеться:** відкрийте SIDEY, щоб надіслати коротке повідомлення або трохи побешкетувати з друзями.
