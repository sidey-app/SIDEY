## Despre SIDEY

SIDEY este o aplicație de mesagerie pentru macOS și Windows. Vorbești cu prietenii prin animale pixelate 2D de la marginea ecranului. Fiecare personaj reprezintă un prieten real și îi arată starea și mesajele scurte în timp ce lucrezi sau te relaxezi.

![SIDEY pe macOS: animalele pixelate schimbă mesaje în partea de jos a ecranului.](assets/sidey-overlay-preview.png)

- Continuă ce făceai: folosește aplicațiile din spatele SIDEY ca de obicei.
- Vezi ce fac prietenii: personajele merg, ațipesc sau dorm pentru a arăta cine este online.
- Spune câteva cuvinte: deschide SIDEY pentru a trimite un mesaj scurt sau a glumi cu prietenii.
