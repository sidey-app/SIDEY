## Sobre o SIDEY

O SIDEY é uma aplicação de mensagens para macOS e Windows. Conversa com amigos através de animais em píxeis 2D na margem do ecrã. Cada personagem representa um amigo real e mostra o seu estado e mensagens curtas enquanto trabalhas ou descansas.

![SIDEY no macOS: animais em píxeis trocam mensagens na parte inferior do ecrã.](assets/sidey-overlay-preview.png)

- Continua o que estás a fazer: utiliza normalmente as aplicações por trás do SIDEY.
- Vê como estão os teus amigos: as personagens caminham, dormitam ou dormem para mostrar quem está online.
- Diz qualquer coisa: abre o SIDEY para enviar uma mensagem curta ou partilhar um momento divertido.
