# SIDEY Windows v1.0.5

업데이트 설치 파일을 내려받을 때 파일 사용 중 오류로 중단되던 문제를 수정했습니다.

## 설치

Release의 `SIDEY-Windows-x64-v1.0.5.msi`를 직접 받아 실행하세요. 설치와 제거에는 관리자 승인이 필요합니다.

v1.0.3 또는 v1.0.4의 앱 내 업데이트에는 같은 오류가 있으므로 v1.0.5를 한 번 수동 설치해야 합니다. 기존 버전 위에 설치하면 현재 설정과 로그인 정보가 유지되며, 이후 업데이트부터는 앱 안에서 받을 수 있습니다.

## 변경 사항

- 업데이트 파일 다운로드와 무결성 확인 뒤 설치기를 정상적으로 실행합니다.
- v1.0.4의 물체 던지기와 아홉 캐릭터 표시는 그대로 제공됩니다.

## 제거

Windows 설정, MSI 또는 `Uninstall.exe`로 제거할 때 설정, 로그와 로그인 정보도 삭제할지 선택할 수 있습니다. 이 옵션은 기본적으로 선택되어 있지 않으며, 선택한 경우 현재 사용자의 SIDEY 데이터가 영구 삭제됩니다.

## 지원 환경

- Windows 11 25H2 이상 x64 PC를 지원합니다.
- 이 버전은 아직 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.
- 기존 per-user 또는 Burn 방식의 Windows 테스트 버전이 설치되어 있다면 먼저 제거하세요.
