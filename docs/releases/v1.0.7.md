# SIDEY v1.0.7

`1.0.7` build `18` · macOS 26+ · Apple Silicon(arm64)

## 변경 사항

- macOS 이모지·기호 선택기에서 고른 이모지가 메시지 입력창에 정상적으로 들어갑니다.
- 친구마다 최근 메시지를 최대 두 개까지 함께 표시합니다. 이전 메시지는 위에, 최신 메시지는 캐릭터 가까이에 표시됩니다.

## 설치 및 업데이트

- 신규 설치는 `SIDEY-macOS-arm64-v1.0.7.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인…` 또는 Homebrew로 업데이트할 수 있습니다.
- 업데이트해도 SIDEY 계정, 그룹, 닉네임과 로컬 설정은 유지됩니다.

## 현재 제한

- 정식판 상점의 실제 캐릭터 판매는 아직 시작하지 않습니다.
- Windows v1.0.6 배포물과 Windows의 무료 캐릭터 정책은 이번 macOS 릴리스에서 변경되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
