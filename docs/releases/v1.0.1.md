# SIDEY v1.0.1

`1.0.1` build `12` · macOS 26+ · Apple Silicon(arm64) · security hotfix

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 앱 내 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 변경 사항

- Realtime 채널을 방 epoch별 DB 이벤트와 일시 이벤트로 분리하고, 클라이언트가 DB형 Broadcast를 위조할 수 없게 차단했습니다.
- 메시지 본문은 Postgres RLS 재조회 뒤 확정하며, 타이핑과 캐릭터 리액션은 서버 RPC가 방·사용자·이벤트 종류·전송 빈도를 검증합니다.
- 초대 코드 검증 정보를 Data API에서 숨긴 private HMAC 저장소로 옮기고 코드를 128-bit 형식으로 강화했습니다.
- 방별 메시지 outbox와 동일 UUID 재시도로 방 전환 중 실패 본문 유출과 응답 유실 뒤 중복 전송을 막았습니다.
- Realtime 재연결 때 Presence·멤버·최근 메시지를 다시 맞추고, 메시지 기록과 이벤트 버퍼의 장시간 메모리 사용량을 제한했습니다.
- 오래된 정상 익명 계정이 삭제되지 않도록 정리 조건을 제한하고, 초대·방 정원·메시지 전송의 병렬 rate/limit 경합을 서버에서 직렬화했습니다.
- 설정창에 macOS 네이티브 타이틀바 재질을 적용하고 온보딩 캐릭터 선택을 4열로 정리했습니다.

## 업데이트 후 확인

- 기존 짧은 초대 코드는 보안상 비활성화됩니다. 각 그룹 방장은 그룹 설정에서 새 초대 코드를 한 번 재발급해야 합니다.
- 서버 계약이 함께 바뀌는 hotfix이므로 `v1.0.0` 이하 클라이언트는 더 이상 기존 Realtime topic을 사용할 수 없습니다.

## 제한 사항

- macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- 12명 실제 방의 30분 장시간 RSS·30 FPS 계측은 지속 검증 항목입니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
