# SIDEY Windows v1.0.10

## What's Changed

- 프로필의 캐릭터·말풍선·투척물 선택 영역을 각각 5열·4열·4열로 고르게 배치하고 선택 표시와 내용을 중앙에 맞췄습니다.
- 상점에서 캐릭터·말풍선·투척물을 탭으로 전환하고, 필요할 때만 필터를 펼쳐 사용할 수 있습니다. 페이지와 탭을 전환할 때 짧은 애니메이션도 적용했습니다.
- 꾸미기 미리보기의 크기와 말풍선 모양, 걷기·투척 속도와 궤적을 실제 오버레이와 더 가깝게 맞췄습니다.
- 투척하거나 맞을 때 캐릭터가 180도 뒤집히는 문제와 미리보기에서 캐릭터가 깜빡이는 문제를 수정했습니다.
- 업데이트 확인과 다운로드 진행 상태를 표시합니다. 설정창을 닫아 트레이로 보내도 다운로드는 계속됩니다.
- 업데이트 알림을 다른 시스템 알림과 같은 정보 알림 형태로 표시합니다.
- 창을 닫는 도중 남은 화면 작업과 꾸미기 이미지 로딩을 정리해 비정상 종료 가능성을 줄였습니다.
- Windows 상점은 계속 미리보기만 제공하며 구매 기능은 사용할 수 없습니다.
