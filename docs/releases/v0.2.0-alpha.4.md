# SIDEY v0.2.0-alpha.4

`0.2.0` build `6` · macOS 26+ · Apple Silicon(arm64) · pre-release

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 Sparkle 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 변경 사항

- 끊어진 Realtime 채널을 감지해 Presence, 메시지, 그룹 snapshot과 `character_pulse` 수신을 재실행 없이 복구합니다.
- 그룹 카드를 단순화하고 방장 전용 그룹 이름 변경, 멤버 추방, 그룹 영구 삭제 흐름을 추가했습니다.
- 입력창 포커스·draft·타이핑 종료 처리를 다듬고, 오버레이 영역의 직접 드래그를 제거해 프리셋 배치를 일관되게 유지합니다.
- 배포본을 Developer ID Application과 Hardened Runtime으로 서명하고 Apple 공증·ticket staple을 적용했습니다.
- 로컬 개발본은 `Sidey-dev`·`development` 채널로 분리하고 Sparkle 자동·수동 업데이트를 비활성화했습니다.

## 제한 사항

- 아직 alpha이며 macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
