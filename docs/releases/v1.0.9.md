# SIDEY v1.0.9

`1.0.9` build `20` · macOS 26+ · Apple Silicon(arm64)

## 변경 사항

- 내 프로필에서 보유한 말풍선과 투척물을 선택할 수 있습니다.
- 선택한 꾸미기는 프로필 저장 없이 모든 그룹에 바로 적용됩니다.
- 기본 말풍선과 캐릭터 기본 투척물로 언제든 되돌릴 수 있습니다.

## 설치 및 업데이트

- 신규 설치는 `SIDEY-macOS-arm64-v1.0.9.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인…` 또는 Homebrew로 업데이트할 수 있습니다.
- 업데이트해도 SIDEY 계정, 그룹, 닉네임과 로컬 설정은 유지됩니다.

## 현재 제한

- 정식판 상점의 실제 판매는 아직 시작하지 않습니다.
- 프로필에는 현재 보유한 말풍선과 투척물만 표시됩니다.
- Windows v1.0.6 배포물과 Windows의 꾸미기 지원 범위는 이번 macOS 릴리스에서 변경되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
