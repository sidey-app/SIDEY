# SIDEY v1.0.2

`1.0.2` build `13` · macOS 26+ · Apple Silicon(arm64) · Presence hotfix

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 앱 내 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 변경 사항

- 초대 코드로 그룹에 참여할 때 기존 멤버의 초기 Presence가 snapshot보다 먼저 도착해도 이벤트를 보존하고 UUID 기준으로 병합합니다.
- 새 그룹 참여 직후 갱신 전 로컬 방 목록이 아니라 서버에서 다시 읽은 snapshot을 기준으로 활성 그룹을 결정해, 참여자가 상대 화면에서 오프라인으로 고착되는 문제를 수정했습니다.
- 같은 순서 경합이 타이핑 상태에도 남지 않도록 snapshot 전 typing 이벤트를 함께 보존합니다.

## 업데이트 후 확인

- 서버 migration이나 초대 코드 재발급은 필요하지 않습니다.
- 업데이트 뒤 SIDEY가 자동으로 재실행되면 현재 그룹의 Presence를 새로 게시합니다.

## 제한 사항

- macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- 12명 실제 방의 30분 장시간 RSS·30 FPS 계측은 지속 검증 항목입니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
