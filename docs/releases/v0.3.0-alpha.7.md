# SIDEY Windows v0.3.0-alpha.7

Windows용 SIDEY 테스트 빌드가 macOS판의 핵심 사용 흐름을 대부분 갖췄습니다.

## 설치

Release의 `SIDEY-Windows-x64-v0.3.0-alpha.7-Setup.exe`를 받아 실행하세요. 설치와 제거에는 관리자 승인이 필요합니다.

## 변경 사항

- 처음 실행 설정과 프로필·그룹 관리 화면이 추가되었습니다.
- 다섯 캐릭터의 상태·타이핑·메시지와 최근 기록을 Windows에서도 확인할 수 있습니다.
- 트레이 메뉴, 다중 모니터 배치, 조용히 모드와 업데이트 확인 기능이 추가되었습니다.
- 한국어·영어 표시와 앱 실행·설치 안정성이 개선되었습니다.

## 테스트 버전 안내

- Windows 11 25H2 이상 x64 PC를 지원합니다.
- 자체 서명된 테스트 빌드이며 공인 코드 서명이나 SmartScreen 평판을 제공하지 않습니다.
- SmartScreen, Smart App Control 또는 조직 정책에 따라 설치 파일 실행이 차단될 수 있습니다.
- Windows 실기·장시간 사용·설치 수명주기와 macOS 간 상호운용 검증은 아직 완료되지 않았습니다.
- 보조 모니터, mixed-DPI와 모니터 연결 해제 동작은 Windows 실기 검증 중입니다.
- `v0.3.0-alpha.1`이 설치되어 있다면 먼저 제거해야 합니다. 앱 설정과 로그인 정보는 유지됩니다.
