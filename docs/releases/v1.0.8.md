# SIDEY v1.0.8

`1.0.8` build `19` · macOS 26+ · Apple Silicon(arm64)

## 변경 사항

- 잠긴 꾸미기 상품을 눌러 캐릭터·말풍선·투척물의 실제 움직임을 미리 볼 수 있습니다.
- 친구가 사용하는 새 말풍선과 투척물을 기본 모양 대신 실제 디자인으로 표시합니다.
- 상단 영역에서도 닉네임과 말풍선 글자가 똑바로 표시됩니다.
- 그룹 정보를 변경할 때 실시간 연결이 불필요하게 끊기지 않도록 안정성을 개선했습니다.

## 설치 및 업데이트

- 신규 설치는 `SIDEY-macOS-arm64-v1.0.8.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인…` 또는 Homebrew로 업데이트할 수 있습니다.
- 업데이트해도 SIDEY 계정, 그룹, 닉네임과 로컬 설정은 유지됩니다.

## 현재 제한

- 정식판 상점의 실제 판매는 아직 시작하지 않습니다.
- Windows v1.0.6 배포물과 Windows의 꾸미기 지원 범위는 이번 macOS 릴리스에서 변경되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
