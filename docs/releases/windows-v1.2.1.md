# SIDEY Windows v1.2.1

## 설치

Windows 11 25H2 이상 x64 PC에서 첨부된 `SIDEY-Windows-x64-v1.2.1-Setup.exe`를 실행하세요. 기존 버전 위에 설치하면 설정과 로그인 정보가 유지됩니다.

## 변경 사항

- 앱과 설치 프로그램에서 한국어·영어·일본어·중국어 간체·중국어 번체·우크라이나어·러시아어를 지원합니다.
- 설치할 때 선택한 언어로 앱을 처음 열며, 앱을 바로 실행하지 않아도 다음 실행에 반영됩니다.
- 설정에서 언어를 바꾸면 창과 연결을 다시 시작하지 않고 문구가 즉시 바뀝니다.
- 한국어 문구를 macOS와 자연스럽게 맞추고 각 언어권에 어울리는 표현으로 다듬었습니다.
- 오버레이가 부드럽게 나타나며 Windows에서 애니메이션 효과를 끄면 오버레이와 작업 표시줄 전환도 즉시 표시됩니다.
- 그룹을 만들거나 초대 코드로 참여한 뒤 다음 화면으로 넘어가지 않던 문제를 수정했습니다.
