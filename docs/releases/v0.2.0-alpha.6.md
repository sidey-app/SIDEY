# SIDEY v0.2.0-alpha.6

`0.2.0` build `8` · macOS 26+ · Apple Silicon(arm64) · pre-release

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 앱 내 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 변경 사항

- 설정 카드를 밝고 옅은 적응형 배경으로 바꾸고 Picker·버튼·토글의 오른쪽 끝을 맞췄습니다.
- 사용자 설정이 아닌 개발 세부 정보 섹션을 제거하고 설정·온보딩 안내 문구를 자연스럽게 다듬었습니다.
- 그룹 아이콘을 폭이 짧은 두 사람 아이콘으로 변경했습니다.
- 초대 코드를 복사하면 해당 그룹 행에 3초 동안 `복사 완료`를 표시합니다.
- 기존 설치에서 macOS 키체인 창보다 먼저 사용 목적과 선택 결과를 안내합니다.
- 한 실행에서 인증 컨텍스트와 읽기 결과를 재사용해 키체인 인증 반복을 줄이고, 인증을 거부하면 추가 요청 없이 앱을 종료합니다.
- 한글 닉네임의 마지막 글자가 조합 중인 상태에서 바로 저장해도 누락되지 않게 수정했습니다.

## 제한 사항

- 아직 alpha이며 macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
