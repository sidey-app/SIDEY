# SIDEY v1.0.3

`1.0.3` build `14` · macOS 26+ · Apple Silicon(arm64) · 최근 기록 개선

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 앱 내 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 변경 사항

- 최근 기록을 발신자의 픽셀 캐릭터, 닉네임, 로컬 전송 시각과 메시지 상태를 함께 보여 주는 카드로 개편했습니다.
- 최신 메시지부터 표시하고 목록 하단에 도달하면 50개씩 자동으로 이전 기록을 가져옵니다. 서버 보존 정책에 따라 최대 7일까지 탐색할 수 있습니다.
- 실시간 수신 메시지와 전송 대기·실패 메시지를 페이지 결과에 UUID 기준으로 병합해 중복 없이 유지합니다.
- 탈퇴 등으로 멤버 정보를 찾을 수 없는 발신자는 햄스터 캐릭터와 `알 수 없는 친구`로 안전하게 표시합니다.
- 최초 로딩, 빈 기록, 오류·재시도, 추가 페이지 로딩·오류를 구분하고 방 전환·창 닫기 시 진행 중인 요청과 적재한 페이지를 정리합니다.

## 업데이트 후 확인

- 서버 migration이나 초대 코드 재발급은 필요하지 않습니다.
- 최근 기록 창을 열고 아래로 스크롤하면 이전 기록이 자동으로 이어집니다.

## 제한 사항

- macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- 12명 실제 방의 30분 장시간 RSS·30 FPS 계측은 지속 검증 항목입니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
