# SIDEY v1.0.3

macOS용 SIDEY의 최근 기록 기능을 개선했습니다.

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: DMG를 열고 `SIDEY.app`을 Applications 폴더로 이동

새로 설치할 때는 ZIP이 아닌 DMG를 사용하세요.

## 변경 사항

- 최근 메시지를 한눈에 볼 수 있는 기록 화면이 추가되었습니다.
- 이전 메시지를 더 불러볼 수 있게 되었습니다.
- 메시지 기록 표시 안정성이 개선되었습니다.

## 지원 환경

- macOS 26 이상 Apple Silicon Mac만 지원합니다.
