# SIDEY v1.0.4

`1.0.4` build `15` · macOS 26+ · Apple Silicon(arm64)

## 변경 사항

- 프로필의 닉네임이나 캐릭터를 바꾼 뒤 내 상태가 회색으로 남거나 친구 상태가 빨강·초록으로 흔들리던 문제를 수정했습니다.
- 꾸미기·상점에 별빛 우파루파, 아기 기니피그, 아기 원숭이, 아기 친칠라 카드가 추가되었습니다.
- 정식판 상점은 출시 전까지 잠겨 있으며 결제를 시작하지 않습니다. 이미 사용권이 있는 캐릭터는 프로필과 월드에서 계속 사용할 수 있습니다.
- 캐릭터 결제 준비 구조를 PortOne V2로 전환하고 결제 상태를 서버에서 다시 확인하도록 정비했습니다.

## 설치 및 업데이트

- 신규 설치는 `SIDEY-macOS-arm64-v1.0.4.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인…` 또는 Homebrew로 업데이트할 수 있습니다.
- 업데이트해도 SIDEY 계정, 그룹, 닉네임과 로컬 설정은 유지됩니다.

## 현재 제한

- 실제 캐릭터 판매는 아직 시작하지 않습니다.
- Windows v1.0.3 배포물과 Windows의 무료 캐릭터 정책은 이번 macOS 릴리스에서 변경되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
