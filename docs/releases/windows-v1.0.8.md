# SIDEY Windows v1.0.8

보유한 말풍선과 투척물을 Windows에서도 장착하고, 상점의 모든 꾸미기를 애니메이션 무대로 확인할 수 있습니다.

## 설치

Release의 `SIDEY-Windows-x64-v1.0.8-Setup.exe`를 받아 실행하세요. 설치와 제거에는 관리자 승인이 필요하며, 신규 설치와 업데이트를 계속하려면 설치 화면에서 이용약관에 동의해야 합니다.

기존 SIDEY를 업데이트하면 설정과 로그인 정보를 유지합니다. Windows v1.0.3 또는 v1.0.4는 앱 내 업데이트가 실패하므로 이번 Setup EXE를 직접 받아 설치하세요.

## 변경 사항

- 내 프로필에 말풍선·투척물 선택 영역을 추가했습니다. 계정이 보유한 꾸미기만 표시하며 기본 말풍선과 캐릭터 기본 투척물로 언제든 돌아갈 수 있습니다.
- 장착한 말풍선의 색상·글자색·픽셀 장식을 메시지와 타이핑 표시에 적용합니다.
- 통통 하트, 미니 대포, 삑삑 오리를 실제 오버레이 투척에 적용합니다. 미니 대포는 전용 발사 장치와 충돌 효과를 함께 표시합니다.
- 상점을 캐릭터 4종·말풍선 3종·투척물 3종으로 확장하고, 각 상품의 움직임을 확인하는 30 FPS 상세 미리보기 무대를 추가했습니다.
- Windows 상점은 계속 미리보기만 제공하며 구매 기능은 사용할 수 없습니다.

## 제거

Windows 설정 또는 `Uninstall.exe`로 제거할 때 설정·로그와 로그인 정보를 각각 삭제할지 선택할 수 있습니다. 두 옵션은 기본적으로 선택되어 있지 않으며, 선택한 데이터는 영구 삭제됩니다.

## 지원 환경

- Windows 11 25H2 이상 x64 PC를 지원합니다.
- 이 버전은 아직 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.
