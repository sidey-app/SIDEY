# SIDEY v1.1.0

`1.1.0` build `24` · 2026년 9월 10일 · macOS 26+ · Apple Silicon(arm64)

캐릭터 피격 효과음과 기절 모션을 추가하고 꾸미기 선택 표시를 통일했습니다.

## 변경 사항

- 캐릭터가 맞을 때 투척물별 효과음 8종을 재생합니다.
- 설정의 `소리 → 캐릭터 효과음`에서 소리를 켜고 끌 수 있으며 기본값은 켜짐입니다.
- 10초 안에 10번 맞으면 수면 자세 위로 노란 별과 링이 도는 기절 모션을 6초 동안 보여줍니다.
- 기절 중에는 이동·확대·던지기가 멈추지만 채팅은 계속할 수 있습니다.
- 기절 중 더 맞아도 시간이 늘어나지 않으며 회복 직후부터 다시 피격 횟수를 셉니다.
- 캐릭터·말풍선·투척물의 선택 표시를 보라색 테두리와 체크로 통일했습니다.

## 설치 및 업데이트

- 새로 설치할 때는 `SIDEY-macOS-arm64-v1.1.0.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인` 또는 Homebrew로 업데이트할 수 있습니다.
- 로그인 상태와 그룹 설정은 업데이트 뒤에도 유지됩니다.

## 현재 제한

- 이번 기능은 macOS 직배포판에 적용되며 App Store판과 Windows판에는 포함되지 않습니다.
- 정식판 상점의 실제 판매는 아직 열리지 않았습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시를 보장하지 않습니다.
