# SIDEY v1.0.0

`1.0.0` build `11` · macOS 26+ · Apple Silicon(arm64) · stable release

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 앱 내 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 주요 기능

- 최대 12명의 가까운 친구가 참여하는 초대 전용 비공개 그룹을 제공합니다.
- 온라인·자리 비움·오프라인 상태와 SIDEY 입력창의 타이핑 상태를 픽셀 동물로 표시합니다.
- 최대 200자의 짧은 메시지를 화면 가장자리 말풍선과 최근 기록으로 확인할 수 있습니다.
- 자리 비움 상태는 글자 수가 순환하지 않는 고정 `Zzz`와 부유·투명도 연출로 표시합니다.
- 메시지는 서버에 7일간 보관한 뒤 일일 정리 작업으로 자동 삭제합니다.
- 끊어진 Realtime 채널을 자동 복구하고 Presence·멤버·메시지를 다시 동기화합니다.

## 제한 사항

- macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
