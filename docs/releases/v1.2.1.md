# SIDEY v1.2.1

`1.2.1` build `29` · 2026년 9월 12일 · macOS 26+ · Apple Silicon(arm64)

상점 캐릭터마다 짧은 이야기를 더하고, 캐릭터와 애착 물건의 소개를 나란히 읽기 편하게 정리했습니다.

## 변경 사항

- 상점 캐릭터 7종의 소개를 짧고 귀여운 이야기로 통일했습니다.
- 캐릭터 상세 상단에는 이름만 표시하고, 소개는 아래 캐릭터 카드로 옮겼습니다.
- 나무의 우클릭 정지·걷기 안내를 미리보기 안에 배치했습니다.

## 설치 및 업데이트

- 새로 설치할 때는 `SIDEY-macOS-arm64-v1.2.1.dmg`에서 `SIDEY.app`을 Applications 폴더로 옮기세요.
- 설치 파일명은 `SIDEY.app`이며 실행하면 `SIDEY-DIRECT`로 표시됩니다.
- 기존 사용자는 앱의 `업데이트 확인` 또는 Homebrew로 업데이트할 수 있습니다.
- 기존 로그인 상태와 그룹 설정은 유지됩니다.

## 현재 제한

- 직배포판 상점의 실제 판매는 아직 열리지 않았습니다. 상품은 미리보기로 살펴볼 수 있습니다.
- App Store판은 Apple의 심사·배포 절차를 별도로 따릅니다.
