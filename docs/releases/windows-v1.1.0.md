# SIDEY Windows v1.1.0

2026년 9월 7일

언어를 바로 바꿀 수 있게 하고, 메시지 입력창의 안정성과 캐릭터 미리보기를 개선했습니다.

## 설치

Windows 11 25H2 이상 x64 PC에서 `SIDEY-Windows-x64-v1.1.0-Setup.exe`를 받아 실행하세요.

기존 사용자는 앱의 업데이트 확인 기능을 이용할 수 있습니다. v1.0.3·v1.0.4는 최신 설치 파일을 직접 받아 설치해야 합니다. 기존 정식 MSI에서 업데이트할 때 설정과 로그인 정보는 유지됩니다.

## 변경 사항

- 설정 페이지 하단에서 한국어·영어·일본어를 선택하면 재실행 없이 적용됩니다.
- 영어와 일본어 문구를 자연스럽게 다듬고, 날짜와 시간은 앱 언어와 무관하게 컴퓨터 설정을 따르도록 했습니다.
- 메시지 입력창의 비정상 종료 문제를 수정하고 제목 표시줄 없이 둥근 모서리로 표시합니다.
- 캐릭터의 방향 전환과 휴식, 투척 궤도와 대포 방향을 macOS와 맞췄습니다.
- 상점 캐릭터 미리보기에서 상품 캐릭터를 더블클릭하면 커지고, 친구 캐릭터를 클릭하면 투척물을 던집니다.
- 미리보기 투척물이 보이지 않거나 깜빡이는 문제와 확대 시 흐려지는 문제를 수정하고, 확대 중에도 닉네임을 표시합니다.
- 별빛 우파루파의 평상시 반짝임과 확대 효과, 투척물 충돌 효과를 개선했습니다.
- 프로필의 말풍선·투척물에도 마우스를 올렸을 때 반응을 표시하고, 활성 그룹은 같은 아이콘의 색상으로 구분합니다.
- 업데이트 확인 상태를 마지막 확인 시간 자리에 표시하고, 다운로드 중에는 진행 비율을 보여줍니다.
- 업데이트 설치 취소와 오류를 알기 쉬운 문구로 안내하며, 설치가 끝난 이전 업데이트 파일은 다음 앱 실행 때 정리합니다.

## 알아두세요

- Windows 버전은 공인 코드 서명 전 정식판으로, SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.
- Windows 상점은 미리보기만 제공하며 구매 기능은 사용할 수 없습니다.
