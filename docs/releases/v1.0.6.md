# SIDEY v1.0.6

`1.0.6` build `17` · macOS 26+ · Apple Silicon(arm64)

## 변경 사항

- 네트워크 연결이 끊겼다가 돌아온 뒤 앱을 재실행해야 정상화되던 문제를 수정했습니다.
- 재연결할 때 그룹, 최근 메시지와 친구 상태를 자동으로 다시 맞춰 내 캐릭터가 회색, 친구들이 빨간색으로 반복 표시되던 현상을 수정했습니다.

## 설치 및 업데이트

- 신규 설치는 `SIDEY-macOS-arm64-v1.0.6.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인…` 또는 Homebrew로 업데이트할 수 있습니다.
- 업데이트해도 SIDEY 계정, 그룹, 닉네임과 로컬 설정은 유지됩니다.

## 현재 제한

- 정식판 상점의 실제 캐릭터 판매는 아직 시작하지 않습니다.
- Windows v1.0.5 배포물과 Windows의 무료 캐릭터 정책은 이번 macOS 릴리스에서 변경되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
