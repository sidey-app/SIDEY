# SIDEY Windows v1.0.6

설정 화면과 연결 복구를 개선하고, 계정에 지급된 캐릭터 선택과 그룹 나가기를 추가했습니다.

## 설치

Release의 `SIDEY-Windows-x64-v1.0.6-Setup.exe`를 받아 실행하세요. 설치와 제거에는 관리자 승인이 필요하며, 신규 설치와 업데이트를 계속하려면 설치 화면에서 이용약관에 동의해야 합니다.

기존 정식 MSI는 Setup EXE가 제거한 뒤 같은 위치에 새 버전을 설치하며 설정과 로그인 정보를 보존합니다. v1.0.3 또는 v1.0.4는 앱 내 업데이트가 실패하므로 이번 Setup EXE를 직접 받아 설치하세요. 과거 per-user 또는 Burn 방식의 테스트 버전은 먼저 Windows 설정에서 제거해야 합니다.

## 변경 사항

- 설정 창이 좁아지면 탐색 메뉴가 아이콘으로 접히고 연결 상태가 겹치거나 잘리지 않습니다.
- 일시적인 연결 끊김은 조용히 복구하고, 오래 끊긴 경우에만 알림을 표시합니다.
- 무료 캐릭터와 계정에 지급된 캐릭터를 프로필에서 선택할 수 있습니다.
- 추가 캐릭터 네 종을 상점에서 미리 볼 수 있으며 Windows 구매 기능은 아직 제공하지 않습니다.
- 그룹 나가기와 작업 중 중복 요청 방지를 추가하고 메시지 입력창 포커스와 전송 아이콘을 개선했습니다.
- 설치 위치 선택, 같은 버전 복구·제거와 이전 정식 MSI 업데이트를 지원하는 Setup EXE로 설치 프로그램을 바꿨습니다.

## 제거

Windows 설정 또는 `Uninstall.exe`로 제거할 때 설정·로그와 로그인 정보를 각각 삭제할지 선택할 수 있습니다. 두 옵션은 기본적으로 선택되어 있지 않으며, 선택한 데이터는 영구 삭제됩니다.

## 지원 환경

- Windows 11 25H2 이상 x64 PC를 지원합니다.
- 이 버전은 아직 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.
