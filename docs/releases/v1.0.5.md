# SIDEY v1.0.5

`1.0.5` build `16` · macOS 26+ · Apple Silicon(arm64)

## 변경 사항

- 친구 캐릭터를 클릭해 물체를 던질 수 있습니다. 기본 설정에서는 바로 클릭해 던지고, `우클릭 후 던지기`를 켜면 내 캐릭터를 우클릭한 뒤 10초 동안 여러 번 던질 수 있습니다.
- 여러 데스크탑을 사용할 때 캐릭터를 클릭해도 메시지 입력창이 나타나지 않던 문제를 수정했습니다.
- Mac을 덮었다 다시 열거나 절전 모드에서 깨어난 뒤 내 캐릭터만 회색 연결 중 상태로 남던 문제를 수정했습니다.

## 설치 및 업데이트

- 신규 설치는 `SIDEY-macOS-arm64-v1.0.5.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인…` 또는 Homebrew로 업데이트할 수 있습니다.
- 업데이트해도 SIDEY 계정, 그룹, 닉네임과 로컬 설정은 유지됩니다.

## 현재 제한

- 정식판 상점의 실제 캐릭터 판매는 아직 시작하지 않습니다.
- Windows v1.0.3 배포물과 Windows의 무료 캐릭터 정책은 이번 macOS 릴리스에서 변경되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
