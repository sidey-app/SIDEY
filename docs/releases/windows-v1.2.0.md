# SIDEY Windows v1.2.0

## 변경 사항

- 캐릭터 피격음 8종과 음소거·음량 조절을 추가했습니다.
- 상점에서 투척물을 맞히거나 음량 조절을 마치면 효과음을 확인할 수 있습니다.
- 10초 안에 10번 맞으면 별과 링을 표시하고, 6초 동안 이동·확대·던지기를 제한합니다.
- 캐릭터마다 닉네임의 높이를 일정하게 맞추고 기절 효과가 가려지지 않도록 개선했습니다.
- 캐릭터·말풍선·투척물을 장착하는 동안 진행 상태를 표시합니다.
- Windows에서 애니메이션을 끄면 상점 미리보기와 기절 효과도 정적으로 표시합니다.
- 앱 시작 시 캐릭터를 회색 연결 대기 상태로 먼저 표시합니다.
- 네트워크 단절 감지와 재연결을 개선하고 연결 상태를 눌러 다시 시도할 수 있게 했습니다.
- 설치기에 7개 언어 선택을 추가하고 필수 구성 요소 설치를 개선했습니다.

**전체 변경 내역**: https://github.com/sidey-app/SIDEY/compare/windows-v1.1.1...windows-v1.2.0
