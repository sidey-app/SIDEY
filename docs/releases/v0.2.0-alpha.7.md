# SIDEY v0.2.0-alpha.7

`0.2.0` build `9` · macOS 26+ · Apple Silicon(arm64) · pre-release

## 설치

- Homebrew: `brew install --cask sidey-app/tap/sidey`
- 직접 설치: Release의 DMG를 열고 `SIDEY.app`을 Applications로 이동

새 설치에는 공증된 DMG를 사용합니다. ZIP은 앱 내 업데이트용이며 DMG와 ZIP의 SHA-256 파일을 같은 Release에서 제공합니다.

## 변경 사항

- 비공개 그룹의 최대 인원을 5명에서 12명으로 늘리고 서버에서도 13번째 가입을 거부합니다.
- 메시지는 서버에 7일간 보관한 뒤 일일 정리 작업으로 자동 삭제합니다.
- 빠르게 여러 그룹을 선택해도 마지막 선택만 적용하고, Presence와 최근 메시지가 모두 준비된 뒤 화면을 전환합니다.
- 끊어진 Realtime 채널을 자동으로 다시 만들고 Presence·멤버·메시지를 재동기화합니다.
- 여러 방의 Presence 게시와 멤버 변경 알림을 합쳐 불필요한 중복 요청과 경합을 줄였습니다.
- 메시지 발신자 식별과 서버 시각 검증을 강화해 낙관적 표시와 최근 기록 정렬을 안정화했습니다.
- 그룹 인원과 메시지 보관 기간을 설정·온보딩·최근 기록·공식 웹사이트에 정확히 표시합니다.
- DMG에 설치 배경·Applications 바로가기·Finder 레이아웃을 포함하고 자동 검증합니다.

## 제한 사항

- 아직 alpha이며 macOS 26 이상 Apple Silicon Mac만 지원합니다.
- E2EE는 제공하지 않습니다.
- 보안 화면, DRM 앱, 권한이 높은 앱, 모든 독점 전체화면 게임 위 표시는 보장하지 않습니다.
- Windows 개발 파일은 이 macOS 배포에 포함되지 않습니다.
