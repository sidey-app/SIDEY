# SIDEY v0.3.0-alpha.2

Windows용 SIDEY 알파 버전의 설치와 실행 안정성을 개선했습니다.

## 설치

Release의 `SIDEY-Windows-x64-v0.3.0-alpha.2-Setup.exe`를 받아 실행하세요.

## 변경 사항

- Windows용 설치 기능이 추가되었습니다.
- 앱 실행과 캐릭터 표시 안정성이 개선되었습니다.
- 업데이트와 재설치 과정이 개선되었습니다.

## 알파 버전 안내

- Windows 11 25H2 이상 x64 PC를 지원합니다.
- 현재 설치 파일은 서명되지 않아 SmartScreen 경고가 표시될 수 있습니다.
- 일부 보안 설정에서는 설치 파일 실행이 차단될 수 있습니다.
- 기존 알파 버전이 설치되어 있다면 먼저 제거해야 할 수 있습니다. 앱 설정과 로그인 정보는 유지됩니다.
