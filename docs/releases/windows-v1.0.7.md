# SIDEY Windows v1.0.7

말풍선·온보딩·연결 복구를 다듬고 최근 기록을 서버의 3일 보관 정책과 맞췄습니다.

## 설치

- `SIDEY-Windows-x64-v1.0.7-Setup.exe`를 실행하세요.
- 기존 설치 위에 업데이트하면 설정과 로그인 정보가 유지됩니다.
- Windows 11 25H2 이상 x64 PC를 지원합니다.

## 변경 사항

- 긴 메시지와 여러 말풍선의 배치와 표시를 개선했습니다.
- 기존 프로필과 그룹을 온보딩에서 확인할 수 있고 그룹 설정은 건너뛸 수 있습니다.
- 네트워크와 모니터 구성이 바뀐 뒤 연결과 오버레이를 더 안정적으로 복구합니다.
- 최근 메시지와 기록의 조회·로컬 보관 기간을 생성 후 3일로 맞췄습니다.
- 추가 캐릭터 네 종은 계속 미리보기로 제공하며 Windows 구매 기능은 아직 제공하지 않습니다.

## 현재 제한

- 이 설치 파일은 아직 공인 코드 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.
- 보안 화면, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시를 보장하지 않습니다.
