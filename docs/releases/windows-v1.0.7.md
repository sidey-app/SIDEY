# SIDEY Windows v1.0.7

최근 메시지와 기록의 조회·보관 기간을 생성 후 3일로 맞췄습니다.

## 설치

- `SIDEY-Windows-x64-v1.0.7-Setup.exe`를 실행하세요.
- 기존 설치 위에 업데이트하면 설정과 로그인 정보가 유지됩니다.
- Windows 11 25H2 이상 x64 PC를 지원합니다.

## 변경 사항

- 로컬 메시지 기록과 서버에서 불러오는 최근 기록을 같은 3일 기준으로 맞췄습니다.
- 한국어와 영어의 최근 기록 안내를 3일 기준으로 갱신했습니다.

## 메시지 보관 변경

- 최근 메시지와 기록은 생성 후 3일 동안 제공됩니다.
- 정책 전환 시 이미 3일이 지난 메시지는 영구 삭제되며 복구할 수 없습니다.

## 현재 제한

- 이 설치 파일은 아직 공인 코드 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.
- 보안 화면, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시를 보장하지 않습니다.
