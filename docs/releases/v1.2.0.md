# SIDEY v1.2.0

`1.2.0` build `28` · 2026년 9월 12일 · macOS 26+ · Apple Silicon(arm64)

새 캐릭터와 투척물 미리보기를 추가하고, 캐릭터와 애착 물건을 함께 살펴볼 수 있도록 상점을 개편했습니다.

## 변경 사항

- 아기 수달·아기 돼지·나무 캐릭터를 추가했습니다.
- 눈송이·야구공·왁뿌볼·두쫀쿠와 캐릭터별 애착 물건을 추가했습니다.
- 왁뿌볼의 부서지는 파편과 두쫀쿠의 쭉 늘어나는 모습, 투척물별 효과음을 미리보기에서 확인할 수 있습니다.
- 캐릭터와 별도 판매 애착 물건을 나란히 배치해 각각의 보유·구매 상태를 보여줍니다.
- 미리보기에서 상대 캐릭터를 누르면 애착 물건을 던지며, 무대 오른쪽 위에서 소리를 켜고 끌 수 있습니다.
- 기존 캐릭터 구매에 포함됐던 물건의 사용권은 유지됩니다.
- 나무를 우클릭하면 멈추고 다시 우클릭하면 걸어요.
- 설정에서 던지기 활성화를 켠 경우 더블 우클릭 후 친구를 눌러 던집니다.
- 상점 상세창의 빈 공간을 줄이고 선택 표시를 정리했습니다.
- 직배포판의 실행 표시 이름을 `SIDEY-DIRECT`로 변경했습니다.

## 설치 및 업데이트

- 새로 설치할 때는 `SIDEY-macOS-arm64-v1.2.0.dmg`에서 `SIDEY.app`을 Applications 폴더로 옮기세요.
- 설치 파일명은 `SIDEY.app`이며 실행하면 `SIDEY-DIRECT`로 표시됩니다.
- 기존 사용자는 앱의 `업데이트 확인` 또는 Homebrew로 업데이트할 수 있습니다.
- 기존 로그인 상태와 그룹 설정을 유지하며 계정을 새로 만들 필요가 없습니다.

## 현재 제한

- 직배포판 상점의 실제 판매는 아직 열리지 않았습니다. 새 상품은 미리보기로 살펴볼 수 있습니다.
- App Store판은 `SIDEY`로 표시되며 업데이트는 Apple의 심사·배포 절차를 별도로 따릅니다.
- 이번 macOS 릴리스는 Windows 앱을 업데이트하지 않습니다.
