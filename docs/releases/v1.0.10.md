# SIDEY v1.0.10

`1.0.10` build `21` · macOS 26+ · Apple Silicon(arm64)

설정 관리와 그룹 나가기, 상점 탐색을 개선하고 최근 메시지 보관 기간을 3일로 변경했습니다.

## 변경 사항

- 캐릭터를 고르면 바로 적용되고, 작성 중인 닉네임은 다른 변경이 와도 유지됩니다.
- 보유 상품이 없어도 기본 말풍선과 캐릭터 기본 투척물의 장착 상태를 확인할 수 있습니다.
- 상점에서 기본순·가격순 정렬과 보유 상품 숨기기를 사용할 수 있습니다.
- 그룹을 직접 나갈 수 있으며 방장 이전이나 마지막 그룹 삭제 영향을 미리 안내합니다.
- 그룹 멤버가 바뀔 때 필요한 그룹만 다시 연결해 현재 그룹의 연결을 안정적으로 유지합니다.
- 설정의 완료 안내는 3초 뒤 자동으로 닫히고 오류 안내는 직접 닫을 때까지 유지됩니다.

## 설치 및 업데이트

- 새로 설치할 때는 `SIDEY-macOS-arm64-v1.0.10.dmg`를 사용하세요.
- 기존 사용자는 앱의 `업데이트 확인` 또는 Homebrew로 업데이트할 수 있습니다.
- 로그인 상태와 그룹 설정은 업데이트 뒤에도 유지됩니다.

## 메시지 보관 변경

- 최근 메시지와 기록은 생성 후 3일 동안 제공됩니다.
- 정책 전환 시 이미 3일이 지난 메시지는 영구 삭제되며 복구할 수 없습니다.

## 현재 제한

- 정식판 상점의 실제 판매는 아직 열리지 않았습니다.
- 이번 macOS 설정·상점 개선은 App Store판과 Windows판에 포함되지 않습니다.
- 보안 화면, DRM 앱, 권한이 더 높은 앱, 모든 독점 전체화면 게임 위 표시를 보장하지 않습니다.
