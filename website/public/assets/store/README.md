# Store preview mirrors

These PNG and WAV files are byte-for-byte copies of approved assets under
`assets/v1/characters`, `assets/v1/throwables`, and `assets/v1/audio`.
Do not edit the mirrored files by hand. Copy the approved source again when it
changes; `pnpm --dir website test` checks every paid sheet and sound for drift.

Paid artwork: `assets/PAID_ASSET_LICENSE.md`.
Audio provenance and approval: `assets/v1/audio/source-licenses.json` and
`assets/v1/audio/approval.json` (source recordings are CC0-1.0).
