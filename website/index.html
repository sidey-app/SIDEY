친구들이 화면 한쪽에 늘 함께해요.

최대 12명의 가까운 친구가 작은 픽셀 동물이 되어 화면에 머물러요. 상태와 타이핑, 짧은 메시지만 보이고 평소 하던 일은 방해하지 않아요.

macOS 다운로드

macOS 26+ · Apple Silicon · 정식 버전 Windows 11 25H2 x64 · v1.0.3 정식 버전

채팅창을 열지 않아도 누가 곁에 있는지 알 수 있어요.

친구의 상태를 조용히 보여주고, 대화가 필요할 때만 짧게 이어 줘요.

●

상태가 모습으로 보여요

온라인이면 돌아다니고, 자리를 비우면 졸아요. 오프라인이면 웅크려 잠들고 상태 점 색도 달라져요.

•••

타이핑과 짧은 메시지

SIDEY 입력창에 글을 쓰면 말풍선에 점이 나타나요. 보낸 메시지는 캐릭터 위에 잠깐 머물고 서버에서 7일 후 자동 삭제돼요.

×7

더블클릭하면 크게 인사해요

내 캐릭터를 더블클릭하면 잠깐 크게 나타나 친구들의 시선을 끌어요. 남긴 말풍선도 더 쉽게 눈에 들어와요.
