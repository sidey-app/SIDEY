친구들이 화면 한쪽에, 늘 가볍게.

최대 다섯 명의 가까운 친구가 작은 픽셀 동물이 되어 머뭅니다. 상태와 타이핑, 짧은 메시지만 자연스럽게 보이고 평소 작업 흐름은 방해하지 않습니다.

↓ macOS 다운로드

macOS 26+ · Apple Silicon · Alpha Windows 11 25H2 x64 · 개발 중

가까운 연결

채팅창을 열지 않아도, 필요한 만큼만.

친구의 존재를 조용히 보여주고, 대화가 필요할 때만 짧게 이어 줍니다.

●

상태가 모습으로 보여요

온라인이면 산책하고, 자리를 비우면 졸고, 오프라인이면 웅크려 잠듭니다. 점 색상도 함께 바뀝니다.

•••

타이핑과 짧은 메시지

SIDEY 입력창에서 쓰는 동안 말풍선 점이 나타나고, 전송한 메시지는 캐릭터 위에 잠깐 머뭅니다.

↘

평소에는 클릭 통과

기본 오버레이는 포인터 입력을 뒤 앱으로 통과시킵니다. 내 캐릭터와 입력창만 명시적으로 상호작용합니다.

개인정보 경계

친구의 존재만. 화면 속 내용은 보지 않아요.

전역 활동 신호는 마지막 시스템 입력 후 경과 시간과 화면 잠금 상태만 사용합니다. 타이핑 상태는 SIDEY 입력창에서만 발생합니다.

  • 화면 내용
  • 활성 앱 목록
  • 다른 앱에서 누른 키
  • 마우스 좌표
  • 파일 내용
  • 마이크·카메라 데이터
!

Alpha에서 알아둘 점

현재 E2EE는 제공하지 않습니다. 보안 화면, DRM 앱, 권한이 높은 앱 또는 모든 독점 전체화면 게임 위에 항상 표시되는 것도 보장하지 않습니다.
