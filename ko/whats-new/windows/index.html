v2.0.0

2026년 9월 20일
변경 내용 펼치기변경 내용 접기expand_more

Google 계정 연결과 계정 관리 흐름을 정리하고, 채팅·단축키·오버레이 사용성을 크게 개선했습니다.

변경사항

전체 변경 내역: https://github.com/sidey-app/SIDEY/compare/windows-v1.3.1...windows-v2.0.0

  • Google 로그인을 필수 온보딩으로 통합하고, 저장된 로그인 상태를 확인하는 동안 로그인 버튼을 잠가 중복 인증을 막았습니다. ( #217, @aryu1217 )
  • 설정에서 로그아웃하거나 회원 탈퇴할 수 있으며, 계정 연결을 해제하면 실시간 연결과 로컬 상태를 정리한 뒤 로그인 화면으로 돌아갑니다. ( #224, @aryu1217 )
  • 최근 기록에서 바로 메시지를 보내고, 채팅 입력창을 끌어 옮긴 위치를 다음 실행에도 유지할 수 있습니다. ( #224, @aryu1217 )
  • 캐릭터를 한 번 클릭할 때만 채팅 입력창이 열리도록 동작을 바로잡았습니다. ( #224, @aryu1217 )
  • 오버레이·조용히 모드·메시지 입력창·최근 기록 단축키를 원하는 키 조합으로 직접 기록하고 중복 조합을 교환할 수 있습니다. ( #224, @aryu1217 )
  • 조용히 모드에서는 입력 중 표시를 숨기고, 오버레이를 닫을 때 애니메이션이 끝까지 자연스럽게 재생됩니다. ( #224, @aryu1217 )
  • 이미 실행 중인 앱을 다시 열어도 기존 창으로 안전하게 전환되도록 수정했습니다. ( #224, @aryu1217 )
  • 앱에서 상품 가격과 보유 상태를 확인하고 웹 구매 화면으로 이동할 수 있으며, 인증 콜백 복귀와 실시간 타이핑 반응을 개선했습니다. ( #217, @aryu1217 )
  • 설치 파일에 필요한 Windows App SDK와 .NET 런타임을 포함하고, 업데이트·복구·제거 실패 시 복원과 안내를 강화했습니다. ( #197, @patulus )
  • 실시간 연결 오류를 원인별로 안내하고, 앱이 재연결하며 만든 불필요한 오류 메시지는 표시하지 않도록 개선했습니다. ( #169, @patulus )
  • 내 나무의 걷기 상태가 같은 그룹의 사용자에게 공유되도록 개선했습니다. ( #148, @aryu1217 )
  • 밝은 테마와 어두운 테마에서 앱 안의 상태 알림을 더 쉽게 읽을 수 있도록 개선했습니다. ( #166, @patulus )

v1.3.1

2026년 9월 15일
변경 내용 펼치기변경 내용 접기expand_more

2026년 9월 15일

Windows 실행 호환 범위를 넓히고 창 크기 변경, 프로필 선택과 투척물 표시의 안정성을 개선했습니다.

설치

설치 대상은 Windows 10 1809 이상 x64 PC입니다. 첨부된 SIDEY-Windows-x64-v1.3.1-Setup.exe를 실행하세요. 기존 버전 위에 설치하면 설정과 로그인 정보가 유지됩니다.

변경 사항

  • Windows 10 1809 이상 x64로 실행 호환 범위를 넓히고, 지원하지 않는 배경 효과와 아이콘을 기본 표시로 대체했습니다.
  • 창 크기를 바꿀 때 앱이 종료되는 문제를 수정하고, 좁은 창에서도 프로필 입력창과 선택 항목이 잘 보이도록 배치를 개선했습니다.
  • 밝은 테마와 어두운 테마에서 창 버튼을 구분하기 쉽게 하고, 프로필·그룹·상점의 로딩 표시를 개선했습니다.
  • 프로필 갱신 중 캐릭터 선택이 바뀌는 문제를 수정하고, 저장한 닉네임과 캐릭터가 내 그룹에도 함께 반영되도록 개선했습니다.
  • 투척물이 다른 물건으로 표시되는 문제와 상점에서 연속으로 물건을 던질 때 동작이 끊기는 문제를 수정했습니다.
  • 설치 파일과 내부 안정성을 개선했습니다.

알아두세요

전체 변경 내역

  • Windows 앱에서는 구매를 지원하지 않으며, 유료 상품은 연결한 계정의 보유 내역을 확인한 뒤 사용할 수 있습니다.
  • Windows 버전은 공인 코드 서명 전 정식판으로, SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.

새 캐릭터와 투척물을 지원하고 테마 선택과 상점 사용성을 개선했습니다.

설치

Windows 11 25H2 이상 x64 PC에서 첨부된 SIDEY-Windows-x64-v1.3.0-Setup.exe를 실행하세요. 기존 버전 위에 설치하면 설정과 로그인 정보가 유지됩니다.

1.3.0 설치 중 오류가 발생했다면 이 릴리스의 설치 파일을 다시 내려받아 실행하세요.

v1.0.3·v1.0.4는 앱 안에서 업데이트 파일을 내려받지 못하므로 최신 설치 파일을 직접 받아 설치해야 합니다.

변경 사항

  • 아기 수달·아기 돼지·나무와 눈송이·야구공·왁뿌볼·두쫀쿠, 캐릭터별 애착 물건 7종을 미리 보고 보유 상품을 사용할 수 있습니다.
  • 캐릭터와 별도로 판매되는 애착 물건의 가격·보유 상태를 함께 확인하며, 투척물을 장착하지 않으면 기본 말랑공을 사용합니다.
  • 내 나무를 한 번 우클릭하면 걷기를 멈추거나 다시 시작하며, 더블 우클릭 후 던지기를 켜면 내 캐릭터를 두 번 우클릭한 뒤 친구를 클릭해 물건을 던집니다.
  • 밝게·어둡게·Windows 기본값 테마를 선택하고 입력창과 최근 기록에도 적용할 수 있습니다.
  • 상점의 긴 상품명·미리보기·스크롤과 로딩 표시를 개선했습니다.
  • 트레이에서 업데이트를 확인하면 설정창을 열지 않고 Windows 알림으로 결과를 받습니다.
  • 정보 화면에서 문제 확인에 필요한 진단 데이터를 내보낼 수 있습니다.
  • 설치 오류 안내와 내부 안정성을 개선했습니다.
  • 앱 안에서 업데이트할 때 설치가 중단되던 문제를 수정했습니다.

알아두세요

전체 변경 내역

  • Windows 앱에서는 구매를 지원하지 않으며, 유료 상품은 연결한 계정의 보유 내역을 확인한 뒤 사용할 수 있습니다.
  • Windows 버전은 공인 코드 서명 전 정식판으로, SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.

보유한 말풍선과 투척물을 Windows에서도 장착하고, 상점의 모든 꾸미기를 애니메이션 무대로 확인할 수 있습니다.

설치

Release의 SIDEY-Windows-x64-v1.0.8-Setup.exe를 받아 실행하세요. 설치와 제거에는 관리자 승인이 필요하며, 신규 설치와 업데이트를 계속하려면 설치 화면에서 이용약관에 동의해야 합니다.

변경 사항

  • 내 프로필에 말풍선·투척물 선택 영역을 추가했습니다. 계정이 보유한 꾸미기만 표시하며 기본 말풍선과 캐릭터 기본 투척물로 언제든 돌아갈 수 있습니다.
  • 장착한 말풍선의 색상·글자색·픽셀 장식을 메시지와 타이핑 표시에 적용합니다.
  • 통통 하트, 미니 대포, 삑삑 오리를 실제 오버레이 투척에 적용합니다. 미니 대포는 전용 발사 장치와 충돌 효과를 함께 표시합니다.
  • 상점을 캐릭터 4종·말풍선 3종·투척물 3종으로 확장하고, 각 상품의 움직임을 확인하는 30 FPS 상세 미리보기 무대를 추가했습니다.
  • Windows 상점은 계속 미리보기만 제공하며 구매 기능은 사용할 수 없습니다.
