## 기존에 등록한 상품에서 수정할 것

수달·돼지·나무는 기존 제품 ID를 유지하고 설명만 아래처럼 바꾼다.

| 제품 ID | 한국어 설명 | 한국 가격 |
|---|---|---:|
| `character_otter` | 아기 수달 캐릭터를 사용해요. 애착 물건은 별도 판매예요. | 1,100원 |
| `character_pig` | 아기 돼지 캐릭터를 사용해요. 애착 물건은 별도 판매예요. | 1,100원 |
| `character_tree` | 나무 캐릭터를 사용해요. 애착 물건은 별도 판매예요. | 2,200원 |

- 아기 돼지는 **`character_pig`**가 맞다. 이전 화면의 `haracter_pig`와 다르다. 잘못 만든 ID를 삭제해도 철자가 다른 올바른 ID가 막히는 것은 아니다. 이미 올바른 ID로 다시 만들었다면 추가 생성하지 않는다.
- 두쫀쿠·왁뿌볼·나무는 한국 App Store **2,200원**, 직배포 **1,900원**을 유지한다.
- 말풍선 3종은 한국 App Store **2,200원**, 직배포 **1,900원**이다. App Store Connect 가격 변경은 이번에 실행하지 않았다.
- 별빛 우파루파 단품은 기존 로컬 예외 가격 **1,900원**, 미니 대포는 기존 **2,900원**을 유지했다. 실제 App Store Connect 가격은 아직 대조하지 않았다.

기존 ID 거래에는 해당 캐릭터의 애착 물건 권리를 계속 포함한다. 새 단품 ID 거래에는 캐릭터만 지급한다. 새 버전·단품 상품의 심사와 구매 검증이 끝난 뒤 판매 전환 일정을 함께 잡는다. 기존 ID의 신규 판매 중단을 지금 실행하거나 기존 상품을 삭제하지 않는다.

## 캡처와 제출 전 확인

`screenshots/`는 실제 SwiftUI 상세 화면을 개발용 보유 상태로 연 **로컬 UI 검토 캡처**다. 상단 검토 도구와 예상 가격이 포함돼 있으며, StoreKit 조회·실결제가 검증된 심사 스크린샷을 대신하지 않는다. 최종 제출용 캡처는 새 상품 등록과 서버 반영 후 App Store 앱에서 다시 만든다. [Apple 심사 정보 안내](https://developer.apple.com/help/app-store-connect/manage-in-app-purchases/view-and-edit-in-app-purchase-information)

원격 DB migration·verifier/Edge Function 배포, Sandbox 신규 구매·복원·환불·계정 연결 검증, 실제 가격 조회, 최종 심사용 화면, 업로드 이력과 build 번호 확인이 남아 있다. 이번 작업에서 심사 제출·업로드·공개 릴리스·운영 판매 활성화는 하지 않았다.
